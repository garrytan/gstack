# /comms — Global Protected Terms

This file is the authoritative list of terms and phrases that `/comms`
**always** preserves verbatim, on every invocation, without needing an inline
`{{keep: ...}}` marker. Treat any occurrence of a term in this table as if it
were wrapped in `{{keep: ...}}`: preserve character-for-character, never reword,
never paraphrase, never alter casing or punctuation.

**Edit this file directly to add your protected terms.** Rows marked `_e.g._` are
placeholder examples — replace or delete them.

## Matching rules

- **Case-sensitive** by default. "Right to Win" is protected; "right to win" in
  casual prose is not (but flag it as a possible miscapitalisation).
- **Whole-phrase match.** A row protects the exact string, not substrings.
- **Plurals and possessives are NOT auto-protected.** If "Strategic PM" is in the
  table, "Strategic PMs" is not — add a separate row if needed.
- **Conflicts with cuts win for the term.** If a sentence is being deleted but
  contains a pre-approved term, relocate the term — don't drop it.
- **Report which global terms appeared** in the Phase 5 edit report alongside
  inline `{{keep: ...}}` phrases, under "🔒 PROTECTED".

**A land that waits on an earlier CI run now decides on what that run actually did.** If a green run was rerun at the moment land picked it up, a red or still-running rerun used to be ignored and land would start another run. Now the rerun's result counts. Main's own Free Tests run also skips a cancelled run when it looks for the run a land already did, so it reuses the earlier green one instead of running the whole suite again.

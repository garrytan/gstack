- **Pregate no longer fails on test files the repo's own vitest or jest config leaves out.** A selected file under a directory the config excludes (alphaclaw's `tests/live` and `tests/container`, which run only when `OPENCLAW_LIVE_E2E=1` is set) was handed to `npx vitest run`, which exits 1 on "No test files found", so the lanes check reported `fail` and /ship could not get a receipt (alphaclaw#386). Beside other files, vitest skipped it silently and the lane counted it as run. Now the lane asks the runner which files its config would run here (`vitest list --filesOnly`, `jest --listTests`) and names the rest as not applicable, with the reason: not run, not counted as covered, never a failure. A vitest run that still ends on its own "No test files found" for files that exist is read the same way, and a real failure elsewhere in the lane still fails it. Any other runner, and a listing that fails, run every file as before (GST-2146).

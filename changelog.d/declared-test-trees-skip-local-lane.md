- **A repo can keep its tier-only test trees out of /ship's local lane.** A pull request touching tests that only run under a separate tier (alphaclaw's `tests/live/**` and `tests/container/**`, which its test runner skips unless a tier flag is set) made the pregate pick those tests, and the files that import their helpers, and run them locally; the runner found no test files, the lane failed, and /ship wrote no receipt. Declaring `[]` for such a glob in `.gstack/pregate.json` used to do nothing for test files, because a test always selects itself. Now a `[]` on a folder inside a test directory (`tests/live/**`; the directory is `test/`, `tests/`, `spec/` or `__tests__/`) keeps the selected tests under it out of the local lane, and pregate prints one `declared test tree` line per glob with the count it left out, recorded with the rest of the lanes result. Nothing changes without such a declaration. Tests outside the glob still run, a `[]` on any other glob, the whole `test/**` included, never skips a test, and as before a new `[]` counts only once it is on the base branch (or in your own user policy), never from a branch's bootstrap policy. With one, a test `.gstack/always-run.json` names still runs, and whenever the remote gate, the test backend or a platform lane is owed, it still covers every selected test, because only the local run leaves them out.

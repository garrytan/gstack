- **A failed second-model review reports the cause that actually stopped it, and the runner never deletes its own prompt.** When Codex logged a 402 on an early attempt and then failed for good with a 401, gstack called it a used-up budget; the final failure now decides. A request id or a duration that happens to contain "402" no longer reads as a budget stop. Claude Code exiting 0 with `subtype: error_during_execution` and a 402 is now a budget stop instead of a generic provider error, and a Claude Code usage limit is reported as `budget_exhausted` instead of with Codex's usage-limit advice. `gstack-outside-voice run` refuses a `--prompt` that is one of the files the run writes for `--out` (such as `<out>.last-message`) instead of deleting it. When the reviewer's own result file has no final verdict, or its first line names another plan snapshot, Codex's complete closing message is used instead.

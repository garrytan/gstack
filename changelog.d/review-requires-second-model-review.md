**`/review` now always runs its Codex second-model review when Codex is ready, and runs the Red Team on diffs over 200 lines.** Both were documented steps that Claude Opus skipped in every headless session of a recent eval, because `/review` called the Codex pass optional and its end-of-skill check never looked for either. The check now requires a status line that `gstack-outside-voice` prints itself (a legitimate "Codex not installed" or "reviews disabled" skip still passes; a claim in the model's own words, or a hand-written `codex exec`, does not), and requires the Red Team whenever the diff is over 200 lines. `/review` runs Codex through that one command, so a model that rewrites the shell can no longer lose the result. In a headless session, the check also stops the model from ending while reviewers it started in the background are still running. `/gstack-ship` is unchanged.

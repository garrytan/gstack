- **A retaken version constant no longer costs a full re-review (GST-1210).** A repository can declare, in its base branch's `.gstack/ship-policy.json`, `carry_mechanical: { version_constants: [{ path, template }], goldens }`: one whole line matching a literal template with one `{n}` slot (founderstar's `const SAVE_VERSION := {n}`) plus the golden files regenerated from it. When a PR retakes that number after a base merge, `gstack-ship-receipt carry` masks only the constant's digits, compares the file with the usual rule and carries with reason `mechanical version constant (<path> 42 → 43)`, provided HEAD's value is above the base's, the pregate's regen check passed at HEAD and proved every changed golden, and the rest of the product diff is the reviewed one. A logic edit next to the constant, trailing code on its line, a second matching line, a lower value, a missing or failed regen check, or a policy only the PR declares still refuses.

**`gstack-ship-queue ready` and `land` now check a pull request against the branch it targets, not the repository's default branch.** Without `--base`, they take the base from the pull request `--pr` names, so a pull request into a branch like `garrytan/v0.2-plan-wip` is no longer refused with QUEUE_RECEIPT_BASE_MISMATCH when its /ship receipt names that branch. A receipt reviewed against any other branch is still refused, and `ready` now refuses an explicit `--base` that isn't the pull request's base. (GST-3445)

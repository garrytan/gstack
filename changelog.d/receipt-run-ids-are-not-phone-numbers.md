- **`gstack-post` no longer reads a ship receipt's CI run ids as phone numbers.** A receipt's `ci_carried` entries carry 11-digit GitHub Actions run ids, and the phone-number check flagged each one, so every PR body with carried CI stopped for `--confirm`. Run ids in the receipt's run-id fields (`ci_carried[].run`, `flaky_exception[].runs`, `issues.flakes[].run`) now pass when the block is one the receipt writer rendered: closed, schema-valid and byte-identical to its own rendering. The same number in prose, beside the block, under any other receipt key, or inside a hand-written or malformed receipt block still needs confirmation (GST-2047).

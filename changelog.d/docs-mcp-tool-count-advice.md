**New guide section: you don't need to cut back on MCP servers for accuracy, up to about 300 tools, as long as Claude Code's tool search stays on.** It sits under "Do you need to cut back on MCP servers?" in USING_GBRAIN_WITH_GSTACK.md and gives the November 2026 test's numbers for each agent. Turning tool search off dropped Claude Code from 92.9% to 85.4% right at 300 tools and doubled the cost per request. Codex and OpenClaw also held up at 300 tools, but they rarely used tools that gbrain unlocked partway through a session (13 of 131 trials and 0 of 131), so gbrain users on those agents should register the full tool set with `gbrain serve --surface full`. Cost and security are still good reasons to remove servers you don't need. BROWSER.md now says its case against browser MCP servers is about cost, speed and reliability, not accuracy.

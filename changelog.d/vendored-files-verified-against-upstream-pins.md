Repos that copy open-source files unchanged can now prove it. List the upstream repositories in `review_vendored` on the base branch and pin each copied file in a manifest, and `gstack-vendored-verify` checks that every file is byte-for-byte that upstream's file at a commit on its default branch, a tag or a branch the base names. Run it as a required CI check. A file that doesn't match, can't be fetched, or comes from an unlisted repository, a fork or a merge-queue branch fails with a reason and a fix (docs/vendored-code.md).

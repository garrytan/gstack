- **A Playwright spec that takes `test` from its own fixtures file now runs under `playwright test`, not the unit runner.** pregate marked a spec as Playwright only when the spec itself imported `@playwright/test`. Playwright's fixtures pattern (`export const test = base.extend(…)` in a local module, `import { test } from './fixture'` in every spec) slipped past that, so in a package with vitest a diff that touched only specs ran `vitest run <spec>`, which found no test files and failed the lane. pregate now follows the modules a test takes `test` from, through re-exports and `index` files, and a unit test that imports some other Playwright-based helper keeps its unit runner.
- **`runners` in `.gstack/pregate.json` sends chosen test files to the repo's own command.** Each rule is `{ when: [globs], runner, cwd? }`: the selected files it matches run through `runner` (with `{files}`, relative to `cwd`) ahead of `runner` and detection, first match wins. Use it for tests that must go through a repo entry point, such as Playwright specs whose harness builds the app before it starts. It applies to the local lane only and is frozen under `--policy-from head`.

- **The pre-commit /verify check now fails a check that times out, and always finishes inside Claude Code's 10-minute command limit (GST-3201).** A check that ran out of time used to be listed as "not run", so the commit still got `VERIFY PASS`. Now it is `VERIFY FAIL: <check> TIMEOUT`, and `gstack-checks quick --timeout` bounds the whole pass (540 seconds by default) instead of each check, so the `VERIFY` line always prints before the command is cut off.
- **/ship's review collector no longer reads a reviewer's own scope list or list of passed checks as findings (GST-3201).** A bullet such as "a HIGH finding still refused" in the list of what the tests cover, or "`missing_verdict` can't occur alongside P0 or P1 findings" in the list of checks that held, collected as a HIGH or P0 blocker even though the reviewer declared `REVIEW_VERDICT: blocking=0`. When the reviewer declares no blockers, a plain bullet with no file:line, no Severity or Blocks field and no severity other than one naming findings as a kind is kept on record as informational.
- **Merge-queue stack tests fail when git cannot list a PR's added test files (GST-3201).** That failure used to read as "no new test files" and pass the slot.

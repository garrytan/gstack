**gstack's own use on Capy can be counted, and is kept out of real-use numbers.** Agent-driven sessions on Capy still send no telemetry by default. When the owner's `preferences.yaml` beside the Capy gstack skill holds `telemetry_capy: anonymous`, each skill run there sends one row at the anonymous tier (no device ID, even on a machine set to `community`), labelled `source=capy`, or `source=gt` with `telemetry_capy_source: gt`. Eval and CI labels still win on Capy, unattended sessions elsewhere are unchanged, the ingest function accepts both labels, and the public dashboard's views count only `live` rows. `bin/gstack-telemetry-tier` is the one place that reads these settings.

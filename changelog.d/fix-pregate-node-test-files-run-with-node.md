**Node's built-in test files now run with `node --test` in repos that use vitest or jest.** In a repo whose root package.json declares vitest (a common pnpm monorepo setup), the pre-merge test check ran root `.js`, `.mjs` and `.cjs` files that load `node:test` under vitest, which found no suite in them and failed, so `/ship` stopped at its finish step on every PR that touched one. Those files now get their own `node --test` run, vitest and jest tests keep their runner, and bun repos are unchanged because bun runs `node:test` files itself. Reported by @eoin-obrien in #4586.

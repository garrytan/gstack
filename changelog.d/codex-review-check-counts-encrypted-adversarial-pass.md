**/review on Codex with OpenAI models no longer holds back a review that ran its adversarial pass.** For OpenAI models, Codex encrypts the message it sends a new subagent, so the end-of-session check never saw the adversarial brief's text and blocked the session, then logged a miss. On Codex, a started subagent named `adversarial` whose message is encrypted now counts; a plaintext message still has to carry the brief, a differently named or failed subagent still doesn't count, and Claude Code's check is unchanged. The /review checklist on Codex now asks for that name.

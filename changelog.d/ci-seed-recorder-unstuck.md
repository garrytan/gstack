**The weekly test-time recording can land again on its own.** Free Tests splits the suite using recorded test times, and the weekly job that refreshes them had not landed a refresh since 11-09. Its Windows half ran four files at once on a four-core runner, so tests that pass in the nightly run failed under the load, and the recording had outgrown its 30-minute limit. Its seed pull request also waited on a maintainer whenever a new file ran past 60 seconds. The Windows recording now runs two files at a time with an hour's limit; a trial timed all 921 files cleanly in 38 minutes. The bot now lists each new slow file in the allowlist with a follow-up to split it, and drops files that are back under 60 seconds, so its pull request passes the seed check without a hand edit and its description names every file it listed.

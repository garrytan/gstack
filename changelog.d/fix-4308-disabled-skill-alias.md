- **Disabling `/open-gstack-browser` now takes `/connect-chrome` off too.** `/connect-chrome` is the older name for the same skill, and `gstack-config set disabled_skills open-gstack-browser` left it in Claude Code's skill list. It is now removed with the skill, and a skill of your own named `connect-chrome` is left alone. After you enable the skill again, the next `./setup` brings the old name back.

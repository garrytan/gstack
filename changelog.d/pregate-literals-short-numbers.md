- **The changed-constant check no longer floods on one- and two-digit numbers.** When a constant such as `MAX_ITEMS = 10` changes, a test that only mentions the constant's module counts as a consumer of the old `10` only when that line uses something the test imported from the module (or a variable it got from running it or from such a name), or names the constant. A comment that names the module beside an unrelated `10` no longer blocks the push; on gstack itself, changing `RECEIPT_RUNS_KEPT` (30) flagged 20 test files before and 4 now, and the most any two-digit constant flags fell from 29 files to 13 (#4312). Three-digit and longer values keep the old rule, and negative values such as `-10` follow the same rule as `10`.

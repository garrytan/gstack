- **A Codex outside review that writes its recommendation as a `## Recommendation` heading now counts as finished.** The outside-review parser accepted only an inline `Recommendation: <action> because <reason>` line, so a completed review whose model put the recommendation under a Markdown heading was reported as unavailable (`missing_markers`) in /ship and /codex. The heading and the prose line under it now read as the same marker. A heading with no prose, prose with no `because` reason, a list item or quote under the heading, and a heading inside a code fence still report the recommendation as missing, and severities and blockers are read exactly as before.

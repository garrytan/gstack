- **On Codex, gstack now suggests the right skill for a prompt and stops destructive commands before they run.** `./setup --host codex` (Codex 0.170 or newer) adds two hooks to `~/.codex/hooks.json`: one adds a line naming the gstack skill a prompt fits (review, QA, verify), and one runs /careful's check before every shell command. Codex can't ask you about a single command, so in an interactive session a force-push, `git reset --hard`, `DROP TABLE` or the like is blocked, and the model is told to ask you first; if you want it, type `!` and the command to run it yourself. Under `codex exec` it's a warning instead, and deleting `/` or your home folder stays blocked everywhere. Codex runs new hooks only after you trust them, so pick "Trust all and continue" the next time Codex starts (setup prints a reminder, and `gstack-doctor` shows whether they're trusted). Your own hooks in that file are kept as they are, the same `gstack-config set skill_routing off` and `gstack-config set destructive_guard off` switches work on both hosts, and `gstack-uninstall` or `./setup --no-team` removes only gstack's entries. Setup also suggests `codex -c model_reasoning_effort=high` for gstack work and leaves your `config.toml` alone.

- **`gstack-ship-queue land` stops when `land.merged_checks` change the checkout's git config or hooks.** Land records the config and hooks of the checkout's git directories, the `commondir` and `gitdir` files and the checkout's `.git` that say where git finds them, and every hop of a symlink among them, before the merged-tree checks run. When a check changed or added any of them, land refuses with `QUEUE_LAND_MERGED_CHECKS` naming each path, makes no further git call in the checkout (no merge, no lock-release push) and leaves the land lock held; after restoring the named paths from a trusted copy, `gstack-ship-queue land --pr <n> --pin <sha>` without `--allow-repo-commands` releases the lock without running the checks. Land's git calls in the merged tree run with the checks' environment, and every `gstack-ship-queue` git call now runs with `core.hooksPath=/dev/null` and `core.fsmonitor=false`, so no hook runs there, including one a check writes under a `core.hooksPath` in the checkout's working tree. (GST-1747)

- **`gstack-ship-queue land` keeps `land.merged_checks` out of the checkout's git config and hooks.** Land records the config and hooks of the checkout's git directories, the `commondir` and `gitdir` files and the checkout's `.git` that say where git finds them, and the target of any of those that is a symlink, before the merged-tree checks run; when a check changed or added any of them, land puts them back and refuses with `QUEUE_LAND_MERGED_CHECKS`, so its later git calls (the land-lock push, the merge check) read the config and hooks it started with. Every `gstack-ship-queue` git call now runs with `core.hooksPath=/dev/null` and `core.fsmonitor=false`, so no hook runs there, including one a check writes under a `core.hooksPath` in the checkout's working tree. (GST-1747)

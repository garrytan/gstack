- **For contributors: the paid auto-decide check counts a start step that ran while the skill loaded.** Since Claude Code skills started running their start step as they load, a /plan-ceo-review run that auto-decided its review mode left no start command in its tool calls, so the check that reads the session journal could never credit it. In the captured runs, one of the five passes was credited that way. The check now also reads the skill text Claude Code loaded and accepts the start output it finds there. It still requires exactly one start in the session, and refuses a failed or disabled load or a second start through Bash. The plan-mode and auto-decide paid cases now also run when the load-time helper changes.

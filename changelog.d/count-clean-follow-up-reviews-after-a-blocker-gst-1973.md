- **/ship's finish now counts a chain of follow-up reviews after a granted follow-up review found a blocker.** A granted follow-up review that finds issues has to be logged `converged:false`, and finish refused every chain holding such a link, so a later clean follow-up review that read the fix could not count and only a fresh /ship review recovered the receipt, past the two-round cap. An earlier link that found issues now links when it finished its read on its own commit, its findings account for its counts, and every open or blocking finding names a file it read (a leading `./` on a finding's path names the same file). It counts no path itself, a path its findings name counts only through a clean follow-up review after it, and the `FIX_CHECK:` line marks it `(found issues)`. The chain must still be contiguous, every link still needs its own grant, and the newest link must still be a clean read; a gap, a range that starts mid-link, a newest link with findings, an unfinished read, and findings with no file all still refuse. A finding an earlier link logged on a file that no later clean follow-up review's range touched, even a file the branch never changed, now refuses the chain too, where before it dropped out and the chain counted.

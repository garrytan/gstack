**The prompt-routing hook no longer acts on words inside backticks.** A prompt that quotes a command, such as "Run `mycli check` now" or the line an orchestration tool types to wake a session, was told to run /verify on the trigger "run the checks", and "Run `gh pr review 123`" was told to run /review. A `--fix` flag or the word broken in a pasted log also made a prompt read as a bug report. Triggers and bug-report signs now read only the prose, leaving out inline code and fenced code blocks, on Claude Code and Codex. "run the checks", "review this pr" and bug reports in words route as before, also with code beside them, and an exception name in backticks such as `KeyError` still marks a bug report. Thanks to @vilano93, who found and first fixed it (#4564).

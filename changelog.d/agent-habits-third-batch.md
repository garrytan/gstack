**Three more habits from teams that run evals.** `/eval-plan` says a grader that runs git inside an agent's repo treats that repo as hostile: a sanitized copy of `.git` with no config, hooks, attributes, textconv or signature display, the original index timestamps, no API keys in its environment, and a test that plants each setting. The agents' start card says to find a drive copy in the drive's version history before deleting its source. `docs/working-across-agent-systems.md` says to take each result row's model from the requests the run captured, on every scored row, timeouts included.

**gstack's telemetry backend only accepts writes through its own validated endpoint, and the community dashboard now counts real use.** The public key can no longer read or write the telemetry tables, and a signed-in Supabase user is denied everything. Test runs never send telemetry, test traffic is filtered out of `gstack-community-dashboard`, and its weekly active count is now real installs instead of update checks. The ingest endpoint also keeps whether an event came from a test and stores prompt-injection detections, which it used to drop. Clients older than v0.11.16.0 (March 2026) no longer report usage.

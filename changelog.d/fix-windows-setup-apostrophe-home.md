**`./setup` on Windows now works when your home folder has an apostrophe in its name, such as `C:\Users\O'Brien`.** Git Bash converts `/c/...` paths to `C:/...` before it starts Bun, but it skips any path that holds an apostrophe, so setup stopped with `Module not found`. Setup now converts the paths it hands Bun itself. A Windows run of `./setup` with such a home folder now installs, starts the core skills and runs `/browse`.

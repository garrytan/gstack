- **A finished /ship no longer stops gstack-upgrade for two hours (GST-1205).** Each skill run now records its own entry on the installation's workflow lease and `gstack-skill-end` closes it, so once every run on a session has finished, `bin/gstack-upgrade` and the session-start fast-forward go ahead instead of waiting out the 120-minute window. A run that is still open, or a sibling run on the same harness, still holds the upgrade back. `gstack-lease` gains `release` and `open` (exit 0 while a named run is open), and `list` shows a finished lease as `idle`.

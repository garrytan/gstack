- **docs/pregate.md now describes the secret check's attribute-read exemption for Python and Dart.** #4228 stopped the `env.kv` check from reporting a plain `=` assignment whose whole right-hand side is an unquoted dotted chain of names, such as Django's `session = self.client.session`. The pregate docs now say which lines that covers, that a last keyword argument alone on its line (`password=request.password` with no trailing comma) passes too because the check reads one line, and which forms still report: a quoted value, a bare name, a trailing comma, other text after the value, and every file that isn't Python or Dart. No behavior changed (#4209).

- **/ship's preflight now honors your repository's time limit for rerunning CI-skipped tests, and tells you when a fresh worktree needs its packages installed.** When preflight reuses a CI run and reruns the test files CI skipped, it now stops that rerun at the base branch's `ci_record_timeout_s` (it used 600 s even when the repository set 900 s; accept already honored the setting), and prints the limit it used as `CI_RECORD_TIMEOUT:`. And when the checkout's `package.json` declares packages but there is no `node_modules`, as in a fresh worktree for a second /ship run on the same machine, preflight's test step stops with `STOP: DEPS_MISSING` and the exact install command for the lockfile (for example `bun install --frozen-lockfile`) instead of running checks that can't find the repository's own tools. An installed Yarn Plug'n'Play checkout, which has no `node_modules`, is not stopped. (GST-3360)

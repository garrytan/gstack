- **The /review coverage-audit eval no longer fails a run that really read the source file when zsh stops a command line at an `echo ====` separator.** zsh treats an unquoted word that starts with `=` as a command lookup, so `cat -n src/billing.ts; echo ====; cat -n test/billing.test.ts` prints the source, then `(eval):1: === not found`, and runs nothing after it. The read check now credits the files printed before that error when the error is the last line of the output and everything before it matches the usual read rules; files after the separator still count only when they are read again (gate census 43575953190).

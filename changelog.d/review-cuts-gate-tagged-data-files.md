**Results PRs with large captured agent sessions can be reviewed.** When the gate scan tags a data file (a `.jsonl` transcript, a CSV, a log, or a results JSON) only because a captured session quotes a lint pragma, an env check or a `--no-verify` push on single lines, /ship's readers now get those tagged lines with context instead of the whole file, the same way files with a credential line already work. Code, declared-only files, anything under a test, CI, config or snapshot path, renamed files and files with a tag that spans lines still go to readers whole, and the gate review still runs. A diff that is still over the 2 MB review limit now names its largest files, and a gate-tagged file whose name holds a space is no longer dropped from review.

**Results PRs with large captured agent sessions can be reviewed.** When the gate scan tags a data file (a `.jsonl` transcript, a results JSON, a log) only because a captured session quotes a lint pragma, an env check or a `--no-verify` push, /ship's readers now get those tagged lines with context instead of the whole file, the same way files with a credential line already work. Code files, files tagged by their path and files whose tag spans lines still go to readers whole, and the gate review still runs. A diff that is still over the 2 MB review limit now names its largest files.

- **The prompt-routing hook no longer routes a prompt because of words inside backticks.** A message such as "Run `tool check --run <id>`", which an orchestration tool types into a session to wake it, was sent to /verify on the trigger "run the checks", and "Run `gh pr review 123`" to /review. Triggers now match only the prompt's prose. Inline code and fenced code blocks are left out, as CommonMark reads them, on Claude Code and Codex alike. "run the checks" and "verify my change" route as before, also with code beside them. The bug-report signs still read the code, so an exception name in backticks still counts.

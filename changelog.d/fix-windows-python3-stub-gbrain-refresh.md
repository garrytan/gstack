**`gstack-config gbrain-refresh` no longer deletes your brain-aware skills when `python3` is the Windows Store alias.** Windows keeps the Microsoft Store's `python3` on PATH even next to a python.org install, and it exits 49 without running anything. gbrain-refresh used it anyway, read every detection as "unknown", printed "gbrain not detected" for a healthy gbrain and removed the brain-aware render, including on the refresh that runs after each team-mode auto-update. It now uses the first of `python3` and `python` that actually runs, then its grep fallback, and that fallback no longer ends the run when the detection file has no version. (#1967)

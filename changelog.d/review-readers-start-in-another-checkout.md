- **/ship's review pass works when the checkout you ship isn't the project's default checkout.** On Capy, review readers start in the thread's working directory, and /ship used to stop with `STOP: readers on the shared machine start in <dir>, not in <checkout>` whenever that was a different checkout, for example a project whose default checkout is another repository. Every reader's brief already opens by telling it to `cd` into the shipped checkout and report that checkout's tree on its first line, and a reply naming any other tree or path is still refused, so the pass now dispatches. It still stops before anything starts if readers can't reach the shipped checkout at all, or if they start in another worktree of the same repository, where a reader that skipped the `cd` would quietly review the wrong diff. (GST-3145)

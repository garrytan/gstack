- **Skill start and the gbrain source wireup now find gbrain's config under `GBRAIN_HOME`.** With `GBRAIN_HOME` set, both helpers still looked only at `~/.gbrain/config.json` (#4325). Skill start never printed its `/sync-gbrain` hint on an install whose config lives under `GBRAIN_HOME`. In the wireup, with no explicit or environment URL and no `~/.gbrain/config.json`, no URL was captured, and the ZeroEntropy advisory's config check was silent. With no explicit or environment URL, a non-empty `database_url` in another brain's config at `~/.gbrain` was exported to every `gbrain` call. Both now read `${GBRAIN_HOME:-$HOME}/.gbrain/config.json`, as gbrain does and as gstack-skill-start's own engine check already did.

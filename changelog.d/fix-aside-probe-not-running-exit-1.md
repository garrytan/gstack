- **When the Aside app is closed, browser skills now ask you to open it instead of quietly switching to the headless browser (#4366).** With the app closed, Aside's CLI (1.26.x) exits 1 and says Aside isn't running on this machine. The browser setup probe sent every nonzero exit to `ASIDE_CLI_ERROR`, so the "ask once to open the app" step never fired and `/qa`, `/browse`, `/design-review`, `/canary` and the other browser skills fell back to the headless engine without a word. The probe now reports `ASIDE_NOT_RUNNING` when a nonzero exit carries that message, so you get the prompt to open Aside and retry. Other nonzero exits still report `ASIDE_CLI_ERROR`, and the probe still never prints the CLI's raw output. Contributed by @thehashrocket.

- **The plan-first rule now matches R65.** The captain skill, the CREW template, the lane brief, docs/captain.md and the Capy gstack skill no longer tell a lane that every fix needs a one-round, eng-only plan. A bug fix gets no plan review (`gstack-autoplan next --kind fix`), and its PR carries the proof: a repro on current main or a failing test written first. A feature gets the lean run (`--kind feature`): one reviewer reading the plan and the draft code together. The S1 and audited-problem-list exemptions are unchanged.

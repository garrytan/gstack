- **`gstack-ship-queue ready` now fills in the trial merges and the second-model trail read instead of printing lines to fill.** It lists the open PRs that change a file this PR changes and prints each one's `git merge-tree` result, and with `--trail <decisions.tsv>` it names the reader from the trail's newest `trail-read` row, under a train policy too; a gate, security, money, auth or data PR with no such row prints `MISSING: cross-family trail read`.
- **Five small ship-tool fixes.** `Plan: exempt:` accepts bug-fix wording such as "bug fix with failing-first tests", and ready uses the Plan line `/ship` finish resolved when the PR body has none. `gstack-approvals round-grant` refuses only gstack's own names, so "gstack-evals Captain" can grant a round. The Capy PR hand-off follows `GH_REPO` the way gh's own write does and refuses a PR URL that names another repository, and a pull request opened from a fork names its head as `owner:branch`. A targeted review read on a path with non-ASCII characters now carries across a later docs-only change.
- **A ruling the owner gives while a `/ship` run is open can be relayed.** `gstack-approvals rule --owner-ref <thread>:<message>` records the owner's words with the message they came from and marks the ruling relayed in the record, the receipt and the PR body; without it the refusal now says `APPROVAL_RULING_RUN_OPEN`. `rule --not-security` lets the owner say a red-team finding is not a security finding, so its PR text shows the finding instead of "security finding, details recorded privately"; it is refused while a `/ship` run is open.

A named non-test `.ts`/`.js` file under the repo root that holds a tagged `html`, `css` or `svg` template now counts as a rendered file, using /ship's template rule from `bin/gstack-diff-scope` (one regex, pinned byte for byte by a test), and row, list, picker, menu and section join the UI terms (near a visual noun they add Design; alone they only keep the UI checklist sections loaded). In a lean `--kind feature` run, a phase the one reviewer does not apply as a lens is now labelled with its real reason, such as `no UI scope detected (lean)`, instead of `lean run: merged into the one eng reviewer`.

- **The review plan finishes in about 35 seconds on a 195,000-file results tree, and the pass says so when the plan runs out of time.** The `review_exclude_paths` name scan now writes the code and test files into a scratch index and runs one `git grep` per tree, and the binary check reads small blobs through one `git cat-file --batch` per 64 MB instead of one git call per file. The number of git calls no longer grows with the size of the tree or the PR. On harness-evals #269 the plan went from 2 min 38 s and 432 git calls to 32 s and 76 calls; on #279 it went from 206 s to 35 s, with the same output. When `gstack-review-plan` still runs past the pass's 180-second limit (`GSTACK_REVIEW_PLAN_TIMEOUT_MS` changes it), `gstack-review-dispatch pass` now prints a `REVIEW_PLAN_STOPPED` line naming the step, the reason and the limit instead of exiting with no output.

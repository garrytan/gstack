- **The browse daemon no longer picks port 10080, which Chromium refuses to open.** The daemon and terminal agent draw a random port from 10000-49151, and 10080 is on Chromium's blocked list, so about one start in 39,000 left the browser unable to load the daemon's own pages (the welcome page failed with `net::ERR_UNSAFE_PORT`). A draw on that port is now redrawn. One flaky free test is fixed too. The paid-shard retention check no longer fails when an unrelated short-lived process stops being readable and exits while it scans running processes.

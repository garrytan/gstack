**`/sync-gbrain` no longer imports plans and design docs twice on a machine that is also the brain host, when `GSTACK_BRAIN_SOURCE_ID` names the artifacts source.** The memory stage looked for the federated artifacts source only at the default worktree or the state root, so a source gbrain registered at its own clone path was missed and `ceo-plan` and `design-doc` pages were imported into a second source. The memory stage and the brain sync page check now read the trimmed `GSTACK_BRAIN_SOURCE_ID` first, and a value that names no federated source prints a warning instead of importing again silently.

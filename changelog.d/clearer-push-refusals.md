**`/ship` now tells you what to change when GitHub refuses a push for email privacy.** A push GitHub declines with GH007 (the commit carries an email address your account keeps private) used to be reported as a non-fast-forward, sending you into a pointless merge and a rerun of the release steps. It now says to set `user.email` to your GitHub noreply address and rewrite the commit, and any other refusal from the remote, such as a protected branch, is quoted instead of read as a merge problem.

### Fixed

- **A design-token file is no longer a secret path by its name alone, so a copy edit to one gets the review depth its content earns.** The review planner treated any path with a `token` or `tokens` segment as a secret path and a gate path, so founderstar's `scripts/ui/token.gd` (Godot UI design tokens) pushed a copy-only PR to the full panel with 11 readers. A token-named source or style file (`.gd`, `.css`, `.ts` and the like) now counts as a secret path only when its added or removed lines hold a value the credential scanner behind pregate's secrets check reads as a secret, or have no text to read. Other token files (`token.json`, `tokens.yaml`, a binary token store) still count by name. Secrets, credentials and keychain names still count by name alone, and so do dotenv files (`.env`, `.env.production`, but not `.env.example`), SSH private keys (`id_rsa`, `id_ed25519`) and key-store files (`.pem`, `.key`, `.p12`, `.pfx`, `.jks`, `.keystore`, `.ppk`), which the planner didn't flag before.

- **Installing gstack for a second workflow on the same machine no longer drops the first one (#3561).** When /ship's documentation step installs gstack `--for document-release` on a machine already installed `--for ship`, the install verdict now keeps both workflows (`for=ship,document-release`) as long as both runs pass at the same gstack revision and Bun, so /ship stays admitted for the rest of its run. A failing install, a new revision or another Bun still replaces the verdict.

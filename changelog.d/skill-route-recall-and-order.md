**The prompt router no longer sends a reported defect to /review or /qa, and never routes a message another agent sent.** A prompt now also counts as reporting a defect when it describes a regression ("started with 0.19", "used to work"), a security hole, lost data or a "should X, but Y"; such a report goes to /review or /qa only when it asks for one in that skill's own trigger words ("review my PR, the login page is broken", "find bugs on my site"); and a message from another Claude Code session or a background agent's hand-back is never routed (#4423).

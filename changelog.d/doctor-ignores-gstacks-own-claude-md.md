- **`gstack-doctor` no longer flags gstack's own `CLAUDE.md` as a pasted skill list.** Run from inside a gstack checkout, the doctor read gstack's development guide as the project's `CLAUDE.md`. The guide opens with `# gstack development`, so the whole file counted as one gstack section, and the `CLAUDE.md` row warned that it lists 25 skills and said to replace it with a two-line block. You land in that folder after running a doctor fix such as `cd <install root> && ./setup`, and the bug report template has users of other hosts run the doctor from there. The doctor now skips that file and names it in the row. A real skill list in `~/.claude/CLAUDE.md` or in another project's `CLAUDE.md` still warns. Contributed by @alexanderhaire.

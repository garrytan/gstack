- **`gstack-doctor` no longer warns about gstack's own `CLAUDE.md`.** Run from inside a gstack checkout, the doctor took gstack's development guide for a pasted skill list. The guide opens with `# gstack development`, so the whole file counted as one gstack section, and the `CLAUDE.md` row warned that it lists 25 skills and said to replace it with a two-line block. You are in that folder after any `cd <install root> && ./setup` fix line, and the bug template has users of other hosts run the doctor from there. The row now names the file as skipped. A real list in `~/.claude/CLAUDE.md` or in another project's `CLAUDE.md` still warns.

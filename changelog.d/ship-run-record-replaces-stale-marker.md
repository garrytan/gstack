**A /ship run that stopped or died no longer blocks grants and the next /ship, and a live run past two hours no longer looks finished.** The bare run marker in the checkout's git dir is now a run record with a state (open, stopped, finished, abandoned) that only gstack's commands change: preflight opens it, review starts and finishes, stub, stop and claim keep it fresh, `gstack-ship-receipt stop` marks it stopped, `finish` removes it, and `gstack-skill-end` marks it finished on any outcome. Preflight and the approval guards read that record instead of the 120-minute lease, which another run's touch could prune while the run was still working. A stopped run may record the fix-check grant for its own stop, once per run, and nothing else; rulings relayed with `--owner-ref` still record. A new `gstack-ship-run` command prints the record (`status`) and ends a run that stopped working (`abandon --run <id> --by <who> --reason <line>`), never within 60 minutes of its last beat; a bare marker from an older gstack, or an unreadable record (by its digest), can be abandoned at any age, and every refusal names the state, the age of the last beat, the earliest abandon time and the command. Also: `gstack-ship-receipt stop` binds the stop to the head its last reading row read, a fix-check or a second-model review included, instead of refusing with `STOP_UNBOUND` (#4591); the PR's round count no longer collapses runs that reused one run id at different heads (gstack-evals#406), and preflight refuses a run id the PR body or run record already shows ended.

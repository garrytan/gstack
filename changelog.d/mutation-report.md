**A weekly report shows which small wrong edits gstack's tests fail to catch.** Every Saturday a new workflow, Mutation report, uses StrykerJS to plant small wrong edits in the five `lib/` files with the most landings in the last 30 days, runs the tests that import each file, and lists every edit no test failed on. Before it mutates a file, a positive control makes the file throw on load and checks that those tests fail. If they still pass, the tests never load the file directly and the file is reported without mutation scores. The report never blocks a merge. It is a trial, and its results decide whether mutation testing earns a permanent place.

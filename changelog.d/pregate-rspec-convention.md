- **`/verify` and `/ship` now find the RSpec spec for a Rails file.** Rails loads classes by name, so a file like `app/models/user.rb` is never required by its spec, and pregate reported it as having no test lane. Pregate now follows the RSpec convention: `app/<path>.rb` selects `spec/<path>_spec.rb`, and `lib/<path>.rb` selects `spec/lib/<path>_spec.rb`, when that spec file exists.

Repos that copy open-source files unchanged can now prove it: list the upstream repositories in `review_vendored` on the base branch, pin each copied file in a manifest, and `gstack-vendored-verify` checks every file is byte-for-byte that upstream's file at a commit on its default branch or a tag. Run it as a required CI check; anything that doesn't match, can't be fetched, or comes from an unlisted repository or a fork fails with a reason and a fix (docs/vendored-code.md).

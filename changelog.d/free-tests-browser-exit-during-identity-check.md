**Free test shards no longer fail when a test's browser exits while the runner checks who owns it.** The shard's cleanup tracker treated a browser process that ended on its own during its `ps` identity check as an ownership failure and failed the shard with "native process identity unavailable" (quick-bun-default on main, run 44850005025); a process that is gone now just ends that check, while a failed check of a live process still fails the shard. The Free Tests planning job also gets 10 minutes instead of 5, so a slow GitHub runner start no longer cancels it.

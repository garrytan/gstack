- **`/ship` no longer keeps a whole results file in review because a model reply says "fit (".** The gate scan's focused-or-skipped-test check (RH-1) read every non-prose file, so English like "don't fit (the gap never drops below one space)" in a committed `turns.jsonl` tagged the file and kept it in the reviewers' diff even under `review_exclude_paths`. On harness-evals#333 that put the reader's diff back at 5,120,181 bytes against the 2 MB ceiling and `/ship` stopped with `REVIEW_DIFF_TOO_LARGE` (GST-2006). RH-1 now reads only files a test runner can execute: source files by extension, extensionless scripts, files in a test folder or a project's own test globs that aren't data, and any file renamed from one of those. JSON, JSONL, NDJSON, CSV, TSV, `.log` and `.out` files no longer carry RH-1. Every other gate tag still reads them, and code under an excluded path with `fit(`, `fdescribe(`, `it.only(` or `describe.skip(` is still tagged and kept.

- **The timeline Stop hook no longer times out on Windows.** On a slug-cache miss the hook spawned a detached `--repair` child that runs `gstack-slug` for up to 30s; Claude Code waits on the hook's whole process tree, so the child could hold every miss past the hook timeout (`Hook failed: ... timed out`). The spawn is now skipped on Windows — the inline path still repairs every cache hit — and `GSTACK_TIMELINE_REPAIR_CHILD=1` re-enables it.

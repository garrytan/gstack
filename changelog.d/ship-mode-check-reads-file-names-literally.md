**/ship no longer misses a file-mode change from main on files whose names start with `:`.** A name like `:!tool.sh` or `:(glob)tool.sh` made git refuse /ship's mode lookup on both heads, and the two failures compared as equal, and a name like `:(top)tool.sh` read the mode of a different file, so a merged head could count as reviewed after main changed such a file's mode. Both mode lookups now read the name literally, and a lookup that fails counts as a change that needs review.

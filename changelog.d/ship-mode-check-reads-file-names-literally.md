**/ship no longer misses a file-mode change from main on files whose names start with `:`.** A name like `:!tool.sh` or `:(glob)tool.sh` made git refuse /ship's mode lookup on both heads, and the two failures compared as equal, so a merged head could count as reviewed after main made such a file executable. The lookup now reads the name literally, and a lookup that fails counts as a change that needs review.

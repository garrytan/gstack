- **The stable release no longer waits on the nightly Windows tests (GST-2815).** The nightly Windows free suite never blocks a pull request, but the daily stable cut still treated its red or unfinished results as a reason to skip a commit, so stable stopped moving while one Windows shard kept timing out. The cut now sets that workflow's check runs aside, matched by workflow file, the same way it ignores its own job. Every other check, the required `free-tests` check and the release-gate evidence still block exactly as before.

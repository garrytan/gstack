- **A pull request that only changes human-facing docs now skips the test suites.** It runs the docs lane instead: links on the lines it added resolve, generated pages stay fresh, the credential scan passes, and the few tests that read docs by directory run. Required checks still report success, so branch protection doesn't hang, and pushes to main keep the full suites. Most Markdown in gstack is agent instructions, so the class is a short allowlist (root README.md, docs/**/*.md, changelog.d/*.md) with a denylist on top. SKILL.md, templates, sections, policy docs, captain and crew files, pinned results, preregistrations, generated pages, and any doc a script or test names all still run full CI. One classifier (`gstack-docs-only`) decides the class for CI, pregate, CI carry, /ship's lanes and land. A crashed classifier, an unknown ref, or a push to main always means the full suites run.

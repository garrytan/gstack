**Small fixes to /ship's helper tools.** `gstack-issue-links` no longer turns /ship's `Review-Finding:` trailers (`p1/red-team#3`) into `Refs` lines in the PR body (#4371), and names the commit of every issue mention instead of `commit :` for mentions in older commits on the branch (#4378, reported and first fixed by @Davmunrey). `gstack-ship-receipt read --check-prose` skips the PR body's opening above its first fold when that opening fits the 3-line, 600-character limit, so a result the PR is about ("58 fixed with gstack") is no longer a false counter mismatch. The review fetch check no longer stops /ship when a stage builds the repo's own native binary at a path its committed `.gitignore` names exactly (`bin/gstack-cso-core`). A base ship policy whose only error is its exclusion list no longer also drops an unknown key that merely starts with that list's name. Merge trains accept `--fixes-base-red-file` for gate case names that hold a comma and read `&gt;` and `&apos;` in JUnit names (#4569). Setup's daily onboarding event can no longer be sent twice when a run straddles UTC midnight.

**A fix commit's `Review-Finding:` trailer now closes its finding only after a full review that finished and converged with the fix in its range.** Before, a completed review pass that had made its own fixes (and so hadn't converged), or whose range began after the fix, could close the finding. A security finding known only by its file and line never closes this way or by grant, so its location can't reach the public PR body, and a granted follow-up check whose dispatch ledger is missing no longer counts. (GST-3260)

**A follow-up check after a fix round now sees new files the fix created but has not committed yet.** /ship runs `git add -N` on those files before taking the diff it hands the reader, so the reader is no longer blind to them; when the fix created no file, the reader gets the same bytes as before. (GST-3260)

**A pull request whose granted fix round changed code now gets one last full review of its final head.** Before, the follow-up check that read only the fix was the last review. The plan now adds one full review with no fix round after that check reads the fix clean; a blocking finding there goes to the person who owns the pull request to decide, never to another fix round. A fix round that changed only docs or tests still finishes after its check. (GST-3260)

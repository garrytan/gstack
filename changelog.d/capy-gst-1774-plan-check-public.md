**The plan check works on public repos (GST-1774).** A repo that commits no `.gstack/` can turn the check on per machine with `gstack-config set plan_record warn|require|off`. The mode order is a tracked `plan_record` of warn or require, then `GSTACK_PLAN_RECORD`, then this key, then warn in a Capy session. A typo is rejected, and `PLAN:` names the file. With no tracked policy the key gates `gstack-ship-queue ready` and /ship finish, not land. On a public or unknown-visibility repo, `gstack-approvals render --plan` now writes `Plan: approved (record r-<id>)` in place of the autoplan run id. That id is an opaque hash of the approval row, so the run id, the row id and the ask stay out of the PR body, its edit history and the READY note pushed to origin. `ready` resolves the id to the same row and applies the same rules as before. Render refuses with no output when an approved line does not resolve, instead of printing a misleading `Plan: required`.

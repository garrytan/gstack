- **Correction to the earlier entry "An outside review's no-findings conclusion must now be one complete sentence".** That entry said a review that reports a problem after its no-findings statement "can no longer read as clean". That held only for a problem in the same sentence, after the statement. A problem written before the statement ("The fallback swallows ENOENT; no issues in the diff."), or in a later sentence after a clean Recommendation, still read clean, and so did scopes that name only part of a branch ("in the latest commit", "in the staged changes"). The verdict-line change above retires all of these rules. Now gstack no longer reads a no-findings sentence at all, and a review counts as clean only when the reviewer itself ends with `VERDICT: CLEAN`. A problem the reviewer describes without a severity tag above that line is still the reviewer's call.

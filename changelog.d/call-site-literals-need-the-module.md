- **/ship's changed-number check no longer stops on tests that only share a word with the change (#4478).** When an ordinary property such as `limit: 120` changed to `30`, every test that used the word "limit" and held the number 120 was reported. A test now counts only when it also names the changed module, as `docs/pregate.md` already said; tests that import the module are still reported. Thanks to @dtoelke for the report and first fix.

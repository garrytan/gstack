- **/ship's changed-number check no longer flags unrelated tests when an ordinary property such as `limit` changes.** Lowering `limit: 120` to `30` in one module reported every test that used the word "limit" and held the number 120, whatever it tested. The docs already said a call-site name such as `limit` or `attempts` counts only where the test also names the changed module, but the code applied that to one-character values only. It now applies whatever the value's length; a constant with an uppercase name is matched as before.

**Opted-in telemetry now says why a skill run ended, which coding agent and model family ran it, and whether an upgrade worked.** Each skill run adds a few labels from fixed lists (agent, model family, how it started, why it ended, whether its checks passed, routing setup) and a random id for the agent session, so failures can be traced to the skills, agents and versions that cause them. Upgrades report success or why they failed. CI and eval runs label themselves, and an unmeasured duration is sent empty instead of 0. The opt-in prompt lists the new fields, and anonymous mode now says it sends no device ID but a random per-session id. Every field is listed in docs/privacy.md; nothing new carries code, paths, prompts or repo names.

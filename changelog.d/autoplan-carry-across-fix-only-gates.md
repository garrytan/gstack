- **/autoplan no longer asks the owner to approve the same plan twice after a fixed delta check.** When the phases were at their round cap, a `revise` wrote a gate whose delta check found a High; fixing it and revising again wrote another gate that refused to carry because the first was never answered, so the owner said "do it" a second time for fixes made in response to their first answer. The carry now reuses the owner's last answered gate across gates that were never answered or relayed and hold only unreviewed-delta or already-decided items, after a delta check of every edit since that answer passes. A High, a second failed delta check on the same answer, a relayed gate, a new question for the owner, or a revise that put new scope in the plan still sends the gate to the owner. A `revise` at the round cap now says up front (`NEW_GATE:`) that it writes a new gate and whether that gate can carry. A `GSTACK_AUTOPLAN_CHECKPOINT_DIR` that points at one run's folder is skipped with the folder to use, instead of nesting a checkpoint copy inside it.

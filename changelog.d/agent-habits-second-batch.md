**Habits from nine teams, written into gstack.** The agents' start card says never to write a file back from a read that came back cut off, and to write launch and env files with a file tool or a quoted heredoc. The factory page says a green fake or dry run isn't done until one run drives the real path, and that a check must see your change and count what its name says. The team manual (`crew/docs/captain.md`) says to change the design when review rounds keep finding the same kind of case, to narrow an over-catching safety guard only with a tested exemption, and to move a thread's waits, watches and automations with its work (the rotation handoff and successor brief now carry a Clocks table). `docs/ship-policy.md` says to land review exclusions and secrets allowlist entries in their own PR first. `/eval-plan` asks each plan to record how task machines were checked for answers the agent could read. `docs/working-across-agent-systems.md` treats a relayed approval as a claim and decides harness pins from a repro, not release notes.

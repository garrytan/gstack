- **gstack's script runner and merge-queue checks now also refuse cut-off output.** The helper that runs gstack's own scripts and `bash -c` commands, and the merge queue's branch-ownership, stacked-test, release-version and merge-group record checks, now fail with `SPAWN_OUTPUT_INCOMPLETE` when Bun cuts a command's output off at its read limit, as the pre-push hook and the pre-merge scans already do. The earlier entry about cut-off output said every other gstack command that reads large git or gh output was covered; it was not, because these went straight to Node's `spawnSync`. A new test now stops any gstack command from calling Node's `spawnSync` directly. The 68 files that still do so read only short output or already check for this error; the test lists them, and the list can only shrink. The browser's process-list read is still not covered.

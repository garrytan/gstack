**`/ship` now tells you what to change when GitHub refuses a push for email privacy.** A push GitHub declines with GH007 (a commit carries an email address your account keeps private) used to be reported as a non-fast-forward, sending you into a pointless merge and a rerun of the release steps. It now says to set `user.email` to your GitHub noreply address and rewrite the commits, and any other refusal from the remote, such as a protected branch, is quoted (through the secret scanner) instead of read as a merge problem. (#4738) Reported by @raymondllee

**`gstack-approvals rule` and `round-grant` now say which `--owner-ref` check failed.** A ref in the wrong shape, a missing `--words` and a missing `--by` each get their own line, the shape refusal states what a valid ref looks like, and no invalid-record refusal tells you to rerun `gstack-approvals add` with flags the command you ran doesn't take. (#4718) Idea and first version by @Barack-zero-to-one in #4720

**The merge queue's bisect now accepts a red judge case whose name holds a space.** A judge case such as `setup-browser-cookies/SKILL.md workflow` was refused as outside the gate's plan, because bisect's own id check left out the space that the release bisect and the CI route already allow; all three now share one rule. (#3580) Idea and first version by @Barack-zero-to-one in #4724

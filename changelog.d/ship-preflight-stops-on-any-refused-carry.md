**/ship no longer starts the full test suite on your machine when CI's earlier run can't be reused (GST-3277).** A full `gstack-ship-preflight` now stops with `SHIP_LANE_NOT_CARRIED` whenever a mapped test lane has no verified CI run at this tree, whatever the reason (a base that moved after the run included), the same way `--tests-only` already did; `--run-uncarried-here` still runs the lane here, in either mode. When the lane's workflow has no `workflow_dispatch` trigger, or its run profile accepts no dispatched run, the stop no longer suggests a `gh workflow run` that would fail: it says to merge the base into the branch and push it, or to ask the pull request's author to.

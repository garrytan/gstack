- **The optional Stop hook no longer checks for a test run after the last edit, and /verify asks for it in plain words instead.** With /verify loaded, Opus 5.5 and GPT-6.1 Sol already ran a test after their last edit in 96% and 89% of runs, and the hook's check added between -0.5 and +2 points, inside the noise on both models. The hook's other checks (report labels, specialist dispatches, the adversarial pass) are unchanged. If you wrote your own skill whose contract lists `check_after_last_edit`, that contract is now invalid. The hook then checks none of that skill's items and prints one line naming the file until you delete the item. /verify now says to run the full check after your last edit. It also no longer says it never edits CHANGELOG, because a changelog entry the repo expects with a change is part of the change; /ship still folds branch entries into the release entry.

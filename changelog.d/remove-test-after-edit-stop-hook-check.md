- **The optional Stop hook no longer checks for a test run after the last edit, and /verify asks for it in plain words instead.** With /verify loaded, Opus 5.5 and GPT-6.1 Sol already ran a test after their last edit in 96% and 89% of runs, and the hook's check added between -0.5 and +2 points, inside the noise on both models. The `check_after_last_edit` contract item and the shell-write parser behind it are gone; the hook's other checks (report labels, specialist dispatches, the adversarial pass) are unchanged. A custom skill whose contract still lists that item now reads as an invalid contract, so the hook lets the stop through and prints one line naming the file. /verify now says to run the full check after your last edit, and it no longer says it never edits CHANGELOG: a changelog entry the repo expects with a change is part of the change, and /ship still folds branch entries into the release entry.

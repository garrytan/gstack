- **Free Tests now reports every free-suite result to Trunk Flaky Tests, for detection only.** Each shard keeps bun's JUnit report from every child, the flaky retry included (`--junit-dir`), and a new `trunk-flaky-tests` job uploads them to Trunk's "gstack free suite" collection on same-repository pull requests and main pushes, so Trunk can flag tests that fail and then pass on the same code. Nothing is quarantined or skipped, no job depends on the upload, and an upload failure never turns a check red. A test child that times out or crashes writes no report, so Trunk sees none of that child's results; it also skips the flaky retry, so the flake ledger has no entry for it and the red shard result is the only record. The token lives only in that job, which checks out and runs nothing from the pull request. The flake ledger and the daily flaky pass are unchanged.

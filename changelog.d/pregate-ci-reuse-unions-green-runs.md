**`gstack-pregate` now reuses every green CI run at your exact code, not just the first one it checks.** When a repository declares several run profiles (a Test run and an E2E run, say), each verified run at HEAD's tree counts, so files the second run already passed no longer run again on your machine; a red run, or one that tested other code, still counts for nothing. docs/pregate.md#ci-carry (GST-3381)

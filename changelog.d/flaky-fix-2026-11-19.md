- **Free-suite CI no longer fails before any test runs when Ubuntu's package mirror is slow.** Playwright's system packages and the gate tools are cached per runner image and Playwright version, so a run on a known image installs them with dpkg instead of downloading about 38 MB from archive.ubuntu.com, and apt waits for a timed-out attempt's lock instead of failing the retry in seconds. On 2026-11-19, 27 free-suite and quick-tier jobs failed this way. Two flaky free tests are fixed too: `first-use` now lists several user drives in sorted order on every filesystem, and the gstack-lease lock test waits for the owner line instead of reading a file that was created but not yet written. Two eval checkers stop refusing correct reads: the read-only command grammar accepts `\"` inside double quotes, as bash and zsh do, and the coverage audit follows a `cd` into a subfolder followed by `cd ..` in the next call.

- **Ubicloud runs survive a dead controller machine (GST-1220).** With `UBI_RECOVERY_DIR` set, `scripts/ubicloud/ubi-runner.sh up` writes an encrypted recovery bundle for each VM, and `recover` on another machine rebuilds that VM's state so `pull`, `ssh` and `down` work there; it adopts a VM only after the bundle's key opens it. `up --sink https-put:<presigned URL> --sink-path PATH` starts a pusher on the VM that uploads its results on a timer, so results land even when no controller survives, and `--counted` refuses to start a run that has no recovery bundle. `--pass` now forwards only variables you exported, never the runner's own.

- **/ship's push step now always ends with one line that says whether it pushed (GST-3053).** `gstack-ship-release push` (Step 17) finishes with exactly one of `PUSH: pushed remote=origin ref=<branch> head=<full sha>`, `PUSH: already_pushed remote=origin ref=<branch> head=<full sha>` or `PUSH: failed reason=PUSH_REFUSED|PUSH_REJECTED|PUSH_GIT_FAILED`, so a script or eval grader can tell that /ship pushed by matching that line instead of looking for a `git push` call. Exit status is unchanged. Each reason code has a troubleshooting entry, and the format is documented in docs/unattended.md#push-line. An eval had graded 48 real /ship pushes as "no push" because it searched for the git command. The line's shape changed. The old `PUSH: ALREADY_PUSHED <short sha>` and `PUSH: pushed <short sha> to origin/<branch>` lines are gone, so update anything that matched them.

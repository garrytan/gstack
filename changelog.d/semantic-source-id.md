- **`gstack-decision-search --semantic` honors `GSTACK_BRAIN_SOURCE_ID`.** The related-from-memory block found the artifacts source only when its gbrain path ended in `.gstack-brain-worktree`, so a source registered elsewhere, such as a clone on the brain host, never got the block. When `GSTACK_BRAIN_SOURCE_ID` is set, the semantic lookup now uses that source if it is registered and degrades to the file results if it is not, the precedence `gstack-gbrain-sync` already uses. Unset, nothing changes, and the search never runs unscoped.

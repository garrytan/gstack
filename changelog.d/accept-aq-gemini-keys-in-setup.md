Setup now accepts Gemini API keys that start with `AQ.` (`AQ.Ab...`), which Google AI Studio currently issues. `setup` previously required `AIza`, so a valid key was rejected before the smoke test, and without `--provider` the same key was classified as OpenAI and rejected for not starting with `sk-`. Both prefixes are now accepted, and the live Gemini check redacts an `AQ.` key if an error body echoes it. Fixes #4239.

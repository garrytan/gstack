- **The secrets check stops flagging three kinds of ordinary code as a secret, and catches two misses.** TypeScript types with spaced generic arguments, Python keyword arguments that read a settings constant (`aws_secret_access_key=settings.S3_SECRET_KEY,`), and camelCase dotted field paths (`"form.section.fieldName"`) no longer stop a push. A secret built with `+` from short pieces, or written in a trailing or whole-line comment, is now reported. A secret in any of those positions still fails the check. Template keys, arrays of names and string-literal generic types still report and are documented as known limits. (#4289)

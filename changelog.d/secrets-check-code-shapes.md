- **The secrets check stops flagging ordinary code as a secret, and catches two misses.** JS/TS template keys built from `${…}` slots, TypeScript types like `Pick<Session, "id" | "forkedFrom"> | null`, arrays of loader names such as gbrain's generated operation table, Python keyword arguments that read a settings constant, and quoted dotted field paths no longer stop a push. A secret built with `+` from short pieces, or written in a trailing or whole-line comment, is now reported. A secret in any of those positions still fails the check. (#4287, #4289, #4309)

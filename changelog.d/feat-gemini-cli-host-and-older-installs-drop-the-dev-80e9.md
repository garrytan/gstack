- **gstack installs for Google's Gemini CLI.** `./setup --host gemini` (or `--host gemini-cli`) links every gstack skill into `~/.gemini/skills`, where `gemini skills list` shows them and Gemini CLI loads one with `activate_skill`. Your own skills in that folder are left alone, and `gstack-uninstall` removes only the entries gstack made. `--host auto` picks Gemini CLI only when the `gemini` command is installed, never for a bare `~/.gemini`.
- **Installs made before v1.91.231.0 drop the ~520 MB test toolchain on the next `./setup`.** setup now moves an older full install to production-only dependencies once, restores the full install if that fails, and waits for another `./setup` that is already moving them. A gstack contributor keeps the toolchain by running `bin/dev-setup` (it marks the clone) or `git config gstack.contributor true`.

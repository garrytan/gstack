- **A /ship receipt now provably carries across the one-time move from a version stamp to a changelog fragment.** A repo switching to `merge: direct` has open PRs whose receipts cover their own VERSION, `package.json` version and CHANGELOG entry, which `land --pin` refuses (`QUEUE_LAND_STAMPED`). A new end-to-end test shows that one commit putting those files back at the merge base and moving the entry to `changelog.d/<slug>.md` keeps the receipt: `gstack-ship-receipt carry` accepts it with no base merge, after a clean base merge and after a base merge whose stamp conflicts resolve to the base, and the PR lands through `land --pin`. A code edit riding that commit still refuses. The `QUEUE_LAND_STAMPED` fix in docs/troubleshooting.md now names the carry, with a fresh /ship only when carry refuses. No product behavior changed (GST-2245).

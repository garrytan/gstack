**Every flaky pass in Free Tests is now recorded.** A test that failed and then passed on its one retry in a dispatched Free Tests run (the runs lanes start on their own branches) was never sent to Trunk, and a retry in the quick tier on the install-default Bun wrote a ledger that was thrown away. Dispatch runs now upload to Trunk like pull requests and main pushes, and the quick tier uploads its ledger as `flake-ledger-quick`, so the run summary and `test:health` count it.

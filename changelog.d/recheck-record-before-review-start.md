**A clean recheck of granted fixes now counts even when its brief was written just before the review started.** The review pass writes the recheck's brief, which records what the reviewer reads, and then takes the review's start token. /ship only accepted that record if it was written after the start, so a clean recheck didn't count and the pull request needed an owner's exception to finish. Taking the start now re-dates the record, but only while it still matches what the reviewer was given. (GST-3523)

- **Installing gstack for a second workflow on the same machine no longer drops the first one (#3561).** When /ship's documentation step installs gstack `--for document-release`, the install record keeps /ship's coverage instead of replacing it, so /ship stays allowed to run for the rest of the run. An install at the same checkout, project, gstack revision and Bun now adds its workflow to the record (`for=ship,document-release`) and keeps every component either run checked; a failing install, a new revision or another Bun still replaces the record.

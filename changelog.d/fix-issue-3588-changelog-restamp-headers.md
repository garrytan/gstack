**A version bump can no longer rename or reorder released CHANGELOG sections without being noticed.** When gstack compared a tested commit with its version bumped successor, it accepted any CHANGELOG change that kept the same section texts, so an earlier release heading could be renamed, two releases swapped, or a release moved to the top under the new version, and the change still counted as part of the bump. Now only the branch's own entry may move to the top under the new version, every released section must keep its heading, text and order, and the refusal names the heading that was renamed or the section that moved.

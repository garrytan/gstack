A repository's own test for `review_exclude_paths` no longer pulls excluded files back into review. When a test file that names `review_exclude_paths` pins the pattern list as quoted array entries, a pattern that names one file (such as `wiki/b2/sessions.jsonl`) stays excluded. Example paths the test expects the patterns to match, code that reads the file, other tests that name it, a quoted path passed to a call, and any joined or prefixed form of the path still keep it in review (docs/ship-policy.md).

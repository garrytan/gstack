- **The tree receipt accepts a release output its release tool regenerates.** A `release_tool` that renders content (harness-evals folds `todos.d/` into TODOS.md) writes more than version rewrites, so `gstack-tree-receipt` called the stamp `changed` and a stamped train refused it. With `--allow-repo-commands`, and in `train build --allow-repo-commands`, a `release_outputs` file is now a stamp when the tool, rerun on the current head at its version, writes it byte for byte, the same rule the release PR and the Version Gate apply. Without the flag the tool never runs and the file stays `changed`. (GST-1176)

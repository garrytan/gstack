- **/autoplan no longer gets stuck between phases after Claude Code 2.1.317 compacts a long session.** On 2.1.317 a compaction's boundary names a parent record that is never written to the session file, so the guard's journal reader dropped every record after the compaction and refused each later phase entry on every retry. The boundary now continues from the last record the compaction kept in place (`compactMetadata.preservedSegment.tailUuid`). Boundaries from 2.1.300 and earlier, a tail that is not flushed yet, and lists that name no record of this session read exactly as before. Reported and fixed by @vilano93 in #4200.

**gstack now picks the newest Opus, Fable, Sol and Astra everywhere it chooses a model.** The second-model voice in Codex now defaults to `gpt-6.2-astra`, the plan-review tiers move to `claude-fable-5-2` and `gpt-6.2-sol`, eval judges default to `claude-fable-5-2`, and setup, doctor and the docs name the same models. One table, `lib/model-families.ts`, now holds each family's newest model, so the next release of any of them is a one-line change, and a test fails if gstack's code or skill text names an older one. Which family speaks as the second voice is unchanged (Astra). Users who pinned a model in their config keep it.

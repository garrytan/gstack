- **An unattended /autoplan run on Claude Code no longer says the publication guard is off while it is on.** `gstack-skill-start` printed `autoplan guard: not enforced by this host ... (GUARD_NOT_INSTALLED)` for every unattended session, but Claude Code runs /autoplan's phase hook whatever the session kind, so runs were blocked by a guard their own record said was off. The line now follows the host: on Claude Code with the hook installed it reads `... (GUARD_ENFORCED)`, elsewhere it keeps `GUARD_NOT_INSTALLED`, and `gstack-artifact validate` accepts either in an unattended run's record.
- **A phase report written only in reasoning now gets a denial that says so and names the fix.** When a `true autoplan-published <phase>` message carries no visible text, the guard denies with the new `publication_not_visible` code instead of the generic `publication_missing`, and every publication denial names the exact command (for example `true autoplan-published dx`) and says reasoning does not count. A saved report file still does not count as publication.

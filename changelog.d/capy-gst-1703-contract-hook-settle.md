**The skill contract Stop hook no longer judges a transcript Claude Code hasn't finished writing (GST-1703).** Claude Code can fire Stop about 200 ms before it flushes the turn's last transcript lines. The contract hook read the transcript once, so a finished /investigate run could be blocked for a missing repro because its final test rerun wasn't on disk yet, and a run whose skill load hadn't landed could stop unchecked. The hook now re-reads the transcript, up to 2 seconds, until it holds the stop's final message. It uses the same loop as the /autoplan and /plan-ceo-review gates (`readSettledTranscript` in `lib/skill-gates.ts`).

**Skills that declare gbrain context queries now get them at start.** `/office-hours`, `/plan-ceo-review`, `/design-shotgun`, `/design-consultation` and `/retro` load their declared brain context at skill start when gbrain is configured, as the docs said they did, and `gstack-config set gbrain_context_load off` turns it off (#4329). In a repo whose gbrain policy is read-only, skill start now says code isn't indexed there instead of telling you to run a `/sync-gbrain --full` that won't pin it, and a deny repo gets no gbrain hint or context (#4419). `gstack-harness status` reports `unknown` with the harness's error when its skill list command fails, instead of listing every skill as missing (#4412).

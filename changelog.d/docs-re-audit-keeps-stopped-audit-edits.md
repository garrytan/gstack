**/ship can write its receipt after a docs audit that stopped before saving its snapshot.** Before, when Step 14.5's first docs audit edited a docs file the review leaves out and then stopped as blocked, the re-audit's snapshot could not account for that edit, so `gstack-ship-receipt write` refused on `review_exclude` and no supported path led to a receipt (GST-3502). `gstack-docs-candidate snapshot --carry-stopped <stopped audit's Prepare snapshot>` now carries the stopped audit's edits into the re-audit's snapshot, and two spellings of the same run record path now count as one run.

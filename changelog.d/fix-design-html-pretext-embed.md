**Pages built by `/design-html` from the bundled Pretext copy now run instead of crashing on their first text-layout call.** The skill told the agent to paste `vendor/pretext.js` into the page's own `<script type="module">`, but the bundle only exports `prepare`, `layout`, `prepareWithSegments` and the rest under renamed minified names, so every page threw `ReferenceError: prepareWithSegments is not defined`. The bundle now sits in an inert `<script type="text/plain">` block that the page imports as its own module through a short-lived Blob URL, so the page is still one file with no network requests and works opened from disk or from a local server. A new test builds a page from the exact recipe in the skill and runs it in Chromium. Thanks to @Akkyman2 for finding and diagnosing this (#4855).

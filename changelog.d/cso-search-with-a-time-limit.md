**/cso can search the whole repository in one call, and a daily report now lists its low-confidence hypotheses.** Audits that started used up their 10-minute budget reading one file per helper call, so most files were never read. The new `gstack-cso search <run> <regex>` runs one regular expression over every file in the snapshot. It stops at a hard 60-second limit, even on a pattern that never finishes, prints the matches found so far, and lists the files it did not search (the first 50 by name, then a count). The skill now pages the file list 500 paths at a time, and `report.md` lists daily hypotheses under "Hypotheses (unconfirmed)".

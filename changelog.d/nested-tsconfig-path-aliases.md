- **/ship's pre-gate finds the tests of a monorepo app that imports through its own `@/` alias.** The import graph read `paths` and `baseUrl` from the repository root's tsconfig only, so in an app like `apps/mobile` whose `tsconfig.json` maps `@/*` to `./src/*`, every touched source file failed with `PREGATE_NO_LANE` even with a test right beside it. Each file now takes its aliases from the nearest tsconfig.json or jsconfig.json above it that declares `paths` or `baseUrl`; a nested config that declares neither defers to the next one up, the root config governs the rest, and an `extends` outside the repository is still never followed. Thanks to @dtoelke for the report and the original fix (#4462).

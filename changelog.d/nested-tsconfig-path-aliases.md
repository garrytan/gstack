- **/ship's pre-gate finds the tests of a monorepo app that uses its own `@/` import alias.** The import graph read `paths` and `baseUrl` from the repository root's tsconfig only, so a test in `apps/mobile` that imports `@/media/close-bar` through `apps/mobile/tsconfig.json` was invisible and every source file it covers failed as `PREGATE_NO_LANE`. Each file's aliases now come from the nearest tsconfig.json or jsconfig.json above it that declares `paths` or `baseUrl`; a nested config that declares neither defers to the next one up, and the root config governs the rest.

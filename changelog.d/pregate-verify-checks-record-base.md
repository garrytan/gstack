**/ship no longer accepts a test-gate record taken against a different base branch.** A record cleared while a pull request was stacked on another branch used that branch's policy and CI run profiles, but it still verified after the pull request was retargeted at main with the same code. `gstack-pregate verify --base <branch>` now refuses a record whose base names another branch, and /ship's finish step passes its base, so it reruns the gate against the real base instead. `gstack-pregate clear` also refuses a base that already contains the branch (BASE_CONTAINS_HEAD), as a gate run does, before it reads that base's policy. (GST-3493)

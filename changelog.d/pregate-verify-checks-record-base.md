**/ship no longer accepts a test-gate record taken against a different base branch.** A record cleared while a pull request was stacked on another branch used that branch's policy and CI run profiles, but it still verified after the pull request was retargeted at main with the same code. `gstack-pregate verify --base <branch>` now refuses a record whose base names another branch, /ship's finish step passes its base (so it reruns the gate against the real base), and `gstack-ship-queue ready` and `gstack-ship-receipt write --base` refuse such a record too. `gstack-pregate clear` also refuses a base that already contains the recorded head (BASE_CONTAINS_HEAD), on a branch or a detached checkout, before it reads that base's policy. (GST-3493)

- **Test impact: main receipts and shadow mode (GST-167, part 3).** A free-tests shard on a main push can now record, with `--receipts`, which files passed on the first try and under which key. New `--shadow-select` checks those receipts against GitHub (same repository, push event, first attempt, recent, the right workflow, a head on main, and the tree and commit the run really tested), computes each pull request file's key with main's key code, and prints one line per free file: `would-reuse <run> key=…` or `execute (<reason>)`, plus the share of files and seed time it could have skipped. Anything it can't verify reads `execute (receipts unavailable: …)`. It runs nothing differently; every file still runs. See docs/test-impact.md.

- **/ship's review plan now sends Swift code that touches private user data to the full review panel (GST-3052).** Once `.swift` stopped failing closed, an iOS change that asked for microphone or speech permission, read HealthKit or calendar data, or wrote and deleted users' files on the device planned the light review. Swift lines that request a privacy permission (speech, microphone, HealthKit, calendars, location, camera, photos, tracking) now count as security, and lines that read HealthKit, EventKit or contacts, write, delete or protect files on the device, use an app group container, exclude files from backup, or declare how long data is kept count as user data. Plain SwiftUI views, UserDefaults settings and file reads stay light. Reported from the GHome iOS app's PR review.

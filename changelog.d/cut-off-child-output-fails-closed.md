- **A command whose output was cut off no longer counts as a finished read.** Bun can report exit status 0 for a `spawnSync` child whose output passed the read limit (ENOBUFS), handing back only part of the output. The credential pre-push hook, the pregate secret and literal scans, the sealed-output guard, the ship receipt, review scoping and the other gstack commands that read large git or gh output now treat that case as a failure, named `SPAWN_OUTPUT_INCOMPLETE`, instead of judging part of a diff or file list. Before this, a push whose diff passed 64 MiB could carry a credential past the pre-push hook.

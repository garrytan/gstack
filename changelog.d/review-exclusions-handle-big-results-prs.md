- **Big results PRs now fit under /ship's review ceiling when their transcripts only name a credential.** Under `review_exclude_paths`, a data file used to stay in review for any line that named a credential, so captured model prompts that mention `${OPENAI_API_KEY}`, `$AGENT_API_TOKEN` or a keychain kept every such file (harness-evals#333: 2,610 files). That many kept files pushed the pattern past the 24,000-byte keep-command limit, so it wasn't applied at all, and readers got over 5 MB against the 2 MB ceiling. A line now keeps its file only when it names a credential and carries a value, meaning the credential scan finds a secret on it or a base64 or token run of 20+ characters follows the name. A key name given a value, such as `OPENAI_API_KEY=sk-…` or `"GH_TOKEN": "…"`, now keeps its file too. Files kept only for a secret line are excerpted, so they no longer count toward the keep-command limit, gstack reads them in git calls under that limit, and `DIFF_KEEP:` leaves them out. On harness-evals#333 the reader's diff drops from 5,458,045 bytes to 1,061,721.

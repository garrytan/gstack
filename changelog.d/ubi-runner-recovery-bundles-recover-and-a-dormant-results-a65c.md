- **Ubicloud test VMs survive the loss of the machine that started them.** With `UBI_RECOVERY_DIR` set, `scripts/ubicloud/ubi-runner.sh up` writes an encrypted recovery bundle for each VM, and the new `recover` command rebuilds that VM's local state on another machine so `pull`, `ssh` and `down` work there again (`--owner OLD` adopts another owner's VMs; run it only once the first machine is dead). `up`, `run` and `verify` also gain `--sink https-put:<presigned URL>` with `--sink-path`, which makes the VM push its own heartbeat and results every few minutes so they land even when no controller survives, `--tag key=value`, and `--counted`, which refuses to create a VM without a recovery bundle. `--pass` now forwards only variables you exported before the runner started, never the runner's own recovery secret or sink URL.

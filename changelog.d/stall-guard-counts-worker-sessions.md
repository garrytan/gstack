- **/ship no longer kills a working test run as stalled when the test command starts its workers in their own session.** The stall check measured CPU in the test command's process group only, so under pnpm 11, where `pnpm exec` starts Vitest in a new session, a quiet suite that was busy read as idle and ended `PREGATE_STALLED` after the stall timeout. The check now counts the whole process tree: the command's group plus every descendant reached by parent links. A stall or timeout kill reaches those descendants too, so no worker is left running.

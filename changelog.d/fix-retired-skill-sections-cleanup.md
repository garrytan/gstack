**Upgrading now removes the old `ship` and `cso` skill folders that 1.104.0.0 left behind.** That upgrade removed each folder's `SKILL.md` but not its `sections/` folder, so `ship/` and `cso/` (and their `gstack-` versions) stayed in your skills directory holding only links. Running `./setup` or `/gstack-upgrade` again cleans them up, including on machines that already upgraded. Only links and copies gstack made are removed: a file, link or folder you added inside one of these folders stays where it is.

**`GSTACK_REVIEW_PLAN_TIMEOUT_MS` now raises the review-plan limit everywhere /ship runs the plan, so large repositories can finish /ship.** `gstack-review-dispatch render` and `gstack-ship-preflight` ran `gstack-review-plan` under a fixed 180-second limit while the plan itself and `gstack-review-dispatch pass` read the variable; all four now read it through one parser (a whole number of milliseconds; an empty, zero, negative or non-numeric value keeps 180 s), and render prints the same `REVIEW_PLAN_STOPPED` line as the pass when the plan runs out of time. On a 301,669-file repository the plan takes 255 to 316 seconds on a 2-core machine, so set the variable there: docs/troubleshooting.md#review-plan-stopped. (GST-3398)

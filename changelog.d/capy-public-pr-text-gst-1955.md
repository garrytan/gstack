- **PR text on a public repository no longer names home paths or Capy thread ids, and what a run cost stays out of the machine-written parts.** /ship's receipt block went out with `spend_usd`, the Capy run and thread ids and, after a remote gate, an absolute path under the home directory, and nothing stopped the same details in the prose. On a public repository, or one whose visibility can't be read, `gstack-post` now sends what machines wrote in a public form: the receipt blocks lose every cost, credits or token field, the run and thread become an opaque id that still deduplicates, paths are cut to the file name, and a result line led by an ALL_CAPS label such as `BUDGET_FINAL:` or `CI_CARRY:` drops its cost, credits, tokens and used values. A home path left in a title, body or comment (an absolute path with a `home` or `Users` folder, including WSL, Windows and diff or escaped-JSON forms and paths glued to `file://`, `user@host:`, `**` or `key:`, `/root/`, `~user/`, or a `~/` path into `.gstack`, `.capy` or scratch) or a Capy id other than the platform's badge refuses the post with a `PUBLIC:` line naming the rule and line, never the value. Repo-relative paths such as `app/users/show.ts` and install paths such as `~/.claude/skills/gstack` pass. A cost figure in prose posts with a LOW note, since a write-up may name cost when cost is the lesson. `gstack-ship-receipt carry --pr` posts its receipt in the same public form. Private repositories keep today's text.

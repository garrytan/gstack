**A Captain's ruling after a PR's second review round now ends in a /ship receipt.** The planner, `gstack-ship-receipt claim` and `write` accept the same fix-check grant whether it was recorded with `gstack-approvals round-grant` or as an owner's `review_loop_grant <head>` row. A fix-check grant no longer needs a stop record, so an edit made after review (a docs-audit edit) or a stop gstack could not bind can get one, and its clean fix-check closes the blockers its fix list named without per-finding rule rows; a blocker nothing covers still refuses. gstack now builds the fix-check's diff from the grant's head itself, a fix-check row that doesn't count (`converged:false`, partial hunks) no longer uses up the grant, and a `round-grant --reason` longer than 300 characters is cut in the ask with the full words kept. A /ship run that finished or was abandoned, or whose process is gone, stops holding gstack upgrades at once, and `gstack-ship-run abandon` takes a run whose process is gone without the 60-minute wait. An owner's `review_loop_grant` row recorded with `gstack-approvals add` inside an open /ship run now needs `--owner-ref`, like `round-grant`. (GST-3546)

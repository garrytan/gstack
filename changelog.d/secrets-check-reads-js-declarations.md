**The secrets check now catches keys in JavaScript and TypeScript declarations.** A key written as `const token = "<key>";` (or `let`, `var`, `export const`, a typed declaration, or a class field such as `private apiKey = "<key>";`) in a `.js`, `.ts` or similar file was never flagged; it now is, as `env.kv.js`. Declarations without a string literal, imports, destructuring, and literals that only name a key stay clean. (GST-3500)

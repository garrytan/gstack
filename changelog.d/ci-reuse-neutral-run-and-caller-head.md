**A neutral CI run no longer blocks reuse of a passing run on the same commit, and a reusable-workflow lane clears only from a caller run at your exact commit.** A newer run that concluded `neutral` is now passed over like a skipped one by `gstack-pregate` and `gstack-ci-carry wait`; a newer failed, cancelled, timed-out or unfinished run still blocks reuse. `gstack-pregate clear --remote <lane> --run-url` on a lane that only runs through `workflow_call` now refuses a caller run from another commit with `head_mismatch`, so an old green run can't clear today's code.

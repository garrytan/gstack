- **The Codex readiness check and the second-model review now pick the same model for a custom Codex provider (GST-3089).** `gstack-codex-probe role-ready` refused a custom provider even when its `~/.codex/config.toml` named `gpt-6-astra`, while `gstack-outside-voice run --runner codex-cli` ran whatever that file named, so a session that trusted the check skipped a review that would have run. Both now use one selection. A custom provider's own `model` counts for plan review when it is exactly the selected tier's catalog ID, any other name is refused as `custom_provider_model_not_tier`, and no name stays `custom_provider_requires_model`. Each of these policy refusals prints a `CODEX_MODEL_POLICY: <reason>` line. For the `autoplan` and `spec` gates the runner now also follows the plan-review tier with the stock OpenAI provider, instead of `config.toml`'s model.

**Landing a ready PR no longer depends on a hand-copied gate decision, and the ready note, release PR and squash message say the right thing.** `gstack-ship-queue ready` now writes the signed, applied, non-security gate decisions into the PR's ready note, and landing reads them from there, so a decision recorded on the /ship machine reaches the landing machine without a hand copy; `--accept` still decides what lands. The ready note shows the decision trail's flags from its trail-read row instead of a placeholder, and calls a PR from a fork an outside PR rather than a sibling it trial-merged. Reopening a release PR now rewrites its description. When /ship's finish step left no plan line, the ready note writes the plan's public form, without the plan record's row. A stacked PR's squash message no longer repeats its parent's trailers. docs/ship-budget.md now says how to restart the budget meter for a stopped run whose ledger closed.

- **The prompt-routing hook now suggests skills you install yourself, and no longer sends ordinary bug reports to /qa (GST-3123).** Any installed skill that lists `triggers:` in its own SKILL.md can now be named by the hook next to gstack's /review, /qa and /verify, so a bug-fix skill with a "fix this bug" trigger is suggested for bug reports. One line names at most two different skills, gstack's own skill wins a tie, and a skill whose name or trigger text holds anything but letters, digits, spaces and simple punctuation is skipped, so its text can't break out of the quoted trigger or add markup to the line. gstack's own generated skill copies count as gstack's even without an install marker, so they still never route. Separately, /qa no longer takes bug reports on everyday words ("cannot find" plus "fails", or "call site" and "tests" far apart), while "please test the site" and "find bugs on my site" still route to it. `gstack-skill-route --explain` and the routing log show where each suggested skill came from.

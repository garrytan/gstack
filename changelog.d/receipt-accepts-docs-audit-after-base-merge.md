**`gstack-ship-receipt write` accepts a docs audit that ran before a base merge.** When /ship's docs audit edited a docs file, the branch then merged in its base (bringing new docs files or a new `review_exclude_paths` pattern), and a re-audit at the merged head made no edits, write refused with `RECEIPT_INVALID field=review_exclude` and no documented way out. Write now skips files under the patterns that only the merged base changed, still checks the earlier audits a no-edit re-audit carries, and accepts the reviewed selection when only the base policy moved. A docs file the PR itself changes after the last audit still refuses. (GST-3260)

- **A property read in code is not an internal hostname (#3987).** `gstack-redact` reported `return m.local;`, `if (config.prod) start();` and `if settings.internal:` as `internal.hostname`, because the pattern ends in `.local`, `.prod` or `.staging` and any object with a property of that name matched. A name that sits in one of four code shapes is now read as code: inside `if (` or `while (` with a closing `)`, `&&` or `?`; in a Python `if`, `elif`, `while` or `assert` line that ends in `:`; after `return`; or next to `&&` or `||`. `and`, `or` and `not` alone never qualify, and the check reads at most 200 characters either side, so a longer line is never exempted. A host in a sentence (`deploy to a.prod and b.internal`), behind a port (`if db.internal:5432`), in a URL, an assignment (`HOST=db.internal`), a config value or a quoted string still reports.

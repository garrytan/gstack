- **A property read in code is not an internal hostname (#3987).** `gstack-redact` reported `return m.local;`, `if (config.prod) start();` and `if settings.internal:` as `internal.hostname`, because the pattern ends in `.local`, `.prod` or `.staging` and any object with a property of that name matched. A span that follows a control-flow keyword or logical operator directly and is closed by an expression terminator (`)`, `;`, `:`, `{`, `?`, `&&`, `||`, `and`, `or`, end of line) is now read as code. A host in a sentence, a URL, an assignment (`HOST=db.internal`), a config value or a quoted string still reports. Contributed by @nazarli-shabnam; reported in #3987.

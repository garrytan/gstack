- **Agents no longer comment to people on a maintainer's behalf.** CONTRIBUTING.md (porting step 5, the wave process and issue triage), docs/triage.md, docs/captain.md, docs/support-tiers.md, docs/recommended-harness.md and /modernize used to tell an agent to thank a contributor, explain a close or point to a winner in a GitHub comment. When an agent does the work it now closes or labels with no comment and writes the note as a draft for the maintainer to send; a maintainer can still comment, and credit stays in the PR body and `Co-authored-by:` lines.

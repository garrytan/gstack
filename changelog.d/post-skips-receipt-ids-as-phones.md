- **`gstack-post` stops reading /ship's own receipt identifiers as phone numbers, so posting a /ship PR body no longer needs a confirm.** The receipt's session run id (`<pid>-<epoch>-<8 hex>`, read as an E.164 number when the pid has seven digits, #4480) and all-digit 12-character commit prefixes in its `pregate` and `requires_remote` values used to stop `gstack-post pr-body` with a MEDIUM `pii.phone.e164` finding. The same went for the `SHIP_RECEIPT:` and `CI_CARRY:` lines /ship prints (`heads=`, `carried_from=`, `base_red=`, `ci_carried=<lane>:<run>/<attempt>`). Only those exact values are exempt, in a receipt block the receipt writer rendered and on lines outside code blocks that open with `SHIP_RECEIPT:`, `CI_CARRY:`, `PREGATE:` or `READY_RECEIPT:`. A phone number in prose, in any other code block or field (a receipt line pasted inside one included), or in a hand-written receipt block still needs a confirm.

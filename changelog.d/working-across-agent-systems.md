**New page: working across agent systems.** `docs/working-across-agent-systems.md` says how to run gstack work when more than one agent system touches a repository: one sender per boundary, answer on the pull request, let a filtered workflow ring the other side instead of polling, treat every message as a paid turn, pin the other harness's version and model, and keep runs cheap. It is self-contained, so any agent can be told to read it first.

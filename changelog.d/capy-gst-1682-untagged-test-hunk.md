- **An owner's review-loop exception can route a type-only test edit it names.** After round 2, a one-line test edit that only widened a TypeScript cast (`as unknown as { attest?: … }` gaining `sources: string[] | null`) was forced as changed since review, because any test hunk that removes a line counted as a possible gate edit unless it was literal-only, so `--review-loop-exception` could not route it and the lane needed another grant and fix-check for a cast (GBRA-336). A `.ts`, `.mts` or `.cts` test path the exception's `fix_check.files` names now routes as accepted when every hunk is one gate-diff leaves untagged, swaps lines one for one with each pair differing only inside a cast's `as { ... }` type with no regex or comment on either line, and no changed line, nor the statement around it, holds an assertion, matcher, test name or skip/only call. Any other test hunk stays forced (an early return, a changed value under test, a commented-out or try-wrapped check), and an unnamed path never routes this way. (GST-1682)

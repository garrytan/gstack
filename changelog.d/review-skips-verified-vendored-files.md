Review can now leave out copied open-source files that gstack has verified. When a base branch declares both `review_vendored` and `review_exclude_paths`, a matched file that is byte-for-byte its upstream's file at the pinned commit leaves the reviewers' diff, and a re-pin's deleted files are checked at the old pin. Agent instructions, config, executables, credential lines and gate-tagged files stay in review, so a gate-tagged upstream test file is still read whole. `gstack-review-plan` prints what verified and what didn't, and the verified list is part of the selection the ship receipt binds (docs/vendored-code.md#what-review-leaves-out).

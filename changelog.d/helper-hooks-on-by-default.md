- **gstack's helper hooks are now on by default in Claude Code, OpenClaw and Hermes, and the prompt-routing hook fires on real bug reports.** `./setup` now registers the prompt-routing hook (one line naming the gstack skill a prompt fits), the skill-contract hook (holds /review once if it stops before its specialist reviewers ran), and a new destructive-command hook that runs /careful's check before every Bash and PowerShell command, so `rm -rf`, `DROP TABLE`, force-push and the like ask before they run even when nobody loaded /careful (in `claude -p` and other sessions nobody is watching, it prints a warning instead of asking, so nothing waits on an answer). New OpenClaw and Hermes registrations get the start hook (a one-line note on each turn telling the agent to run a skill's start command). Why: on Opus 5.5, unattended, a hook line naming a skill got it loaded in 58 of 60 sessions, where a skill relying on its description loaded in 0 of 60. The routing hook used to skip any prompt over 8,000 characters and miss bug reports that never say "bug"; it now scores a long prompt's first 4,000 and last 1,000 characters, reads words like error, exception, traceback, crash and fails as a bug, and keeps paths such as `site-packages` whole. On 60 real bug reports it now fires on 40 instead of 22, and on none of 60 plain prompts that are not bug reports, reviews, QA or checks.

  **Upgrading:** the first `./setup` or `/gstack-upgrade` after this release turns these hooks on once and prints what it turned on. An off you chose earlier (a `./setup --no-...` flag, `gstack-config set <name> off` or an environment variable) is kept. An OpenClaw or Hermes start hook that is off stays off on upgrade, and the setup output prints one line saying how to turn it on: `gstack-harness register openclaw --start-hook` (or `hermes`).

  **Turning them off:** `gstack-config set skill_routing off`, `gstack-config set skill_contracts off` or `gstack-config set destructive_guard off` (each takes effect on the next prompt or command), or `./setup --no-skill-routing`, `--no-skill-contracts`, `--no-destructive-guard`. For OpenClaw or Hermes: `gstack-harness register openclaw --no-start-hook` (or `hermes`), or `gstack-config set harness_start_hook off` and `./setup`. Details: docs/skill-routing-and-contracts.md and docs/hosts.md#start-hook.

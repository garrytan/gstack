- **Deleting or renaming a test now checks the files that still list it, even when another test covers it.** Before, if a `dependencies` entry or another test already pointed at the removed test, `/verify` and `/ship` ran only that test and passed, while a curation list that still named the deleted file was never checked (#3536). Those files' tests now run, and a file that names it with no test of its own fails closed.
- **Playwright specs that use a local fixtures file run under `playwright test`.** A spec that takes `test` from a repo module built on `@playwright/test` (Playwright's fixtures pattern, `export const test = base.extend(…)`) was sent to the unit runner, which found no tests and failed (#4347). It now runs through `playwright test` like a spec that imports `@playwright/test` directly.

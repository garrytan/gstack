- **A finished /ship no longer holds back `gstack-upgrade` for two hours (GST-1205).** Each gstack workflow now records its session as a run on the install's lease when it starts and closes that run when it ends, so once every run on a lease has finished the lease stops counting and an upgrade can go ahead. A run that is still open counts for 120 minutes from its own start, and a lease written without a run, or by an older gstack, counts as before. `bin/gstack-lease list` now shows `idle` for such leases, and `bin/gstack-lease open --run <id>` answers whether one run is still open, which lets `gstack-ship-preflight` refuse a base merge in the middle of a /ship and lets gate dispositions stop counting a parked run once its lease has ended.

- **`/ship` now sees every git worktree of a repo when it picks a version.** The check that keeps parallel work from taking the same version only looked in `<workspace_root>/<repo>/<workspace>/`, the layout Conductor uses. Worktrees made by Claude Code, Codex or plain `git worktree add` were invisible, so two of them could pick the same version with no warning. `gstack-next-version` now asks `git worktree list` and still reads the workspace root, which is how separate clones are found. A worktree found both ways counts once, and `workspace_root: null` still turns the scan off.

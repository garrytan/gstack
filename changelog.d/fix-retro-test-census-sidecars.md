- **/retro counts a test runner that lives in `tests/` without a test-style name, and stops counting engine sidecar files as tests.** On a Godot repo whose whole suite is `tests/run.gd`, `TEST_FILES_TOTAL` read 0, because the census only counts conventionally named files (`*.test.*`, `test_*.py`, `FooTests.swift` and the like), while `TEST_FILES_CHANGED` read 2, because it also counted the `tests/run.gd.uid` file Godot writes beside every script. When a repo has no conventionally named test file, the census now counts the code files under `test/`, `tests/`, `spec/` and `__tests__/`, leaving out prose and `.uid`, `.import` and `.meta` files. A repo that does name its tests by convention keeps today's count, so a helper like `tests/utils.py` still does not count there. Godot's `.uid` and `.import` files and Unity's `.meta` files no longer count toward `TEST_FILES_CHANGED` or `TEST_INSERTIONS` anywhere.

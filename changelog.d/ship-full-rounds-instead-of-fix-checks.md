**/ship no longer plans narrow re-checks after a fix.** A fix after the first review round gets a full second round on the fixed range, and a fix in the last allowed round gets one read-only full review of the whole PR, so changed code never ships unread (a light diff's below-floor fixes that change no runtime lines still ship as notes). Each of those rounds keeps at least one full-effort reviewer, the one the narrow re-check was, even on a docs-only change. An approval no longer swaps that final review for a narrow re-check. docs/review-policy.md, docs/ship-policy.md (GST-3562)

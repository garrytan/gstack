- **`/verify` and `/ship` find the tests for two more kinds of source file.** In a TypeScript repo that uses NodeNext imports (`./x.js` for `x.ts`), the test selector now follows those imports to the `.ts` or `.tsx` file, as TypeScript does, even when a compiled `.js` sits beside it (#4398). In a Rails repo, `app/<path>.rb` now selects `spec/<path>_spec.rb` and `lib/<path>.rb` selects `spec/lib/<path>_spec.rb` when that spec exists, at the repo root or under an engine's own root (#4211). Request and system specs, which name no single source file, are not mapped.

- **`/verify` and `/ship` find the tests for two more kinds of source file.** In a TypeScript repo that uses NodeNext imports (`./x.js` for `x.ts`), the test selector now follows those imports to the `.ts` file, so touched sources no longer report "no test lane" (#4398). In a Rails repo, `app/<path>.rb` now selects `spec/<path>_spec.rb` and `lib/<path>.rb` selects `spec/lib/<path>_spec.rb` when that spec exists (#4211).

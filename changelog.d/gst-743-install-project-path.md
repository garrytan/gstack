- `install.sh --project` (through `gstack-capy-install`) keys the install verdict the way pregate admission reads it: by the project's git toplevel, so `--project <repo>/<subdir>` and `--project <repo>` write the same verdict. A value that is not a directory, such as a repo slug, is a usage error that asks for the checkout's path, raised before anything is cloned or installed. Before, a slug or a subdirectory keyed the verdict somewhere admission never looks, so a later pregate admission check read a stale verdict (GST-743).

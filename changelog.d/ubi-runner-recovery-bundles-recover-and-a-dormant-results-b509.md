- **A Ubicloud test VM no longer gets stranded when the machine that started it dies (GST-1220).** With `UBI_RECOVERY_DIR` set, `scripts/ubicloud/ubi-runner.sh up` writes an encrypted recovery bundle of the VM's ssh key and settings, and `ubi-runner.sh recover` on another machine rebuilds that state so `pull`, `ssh` and `down` work there. `recover` adopts a VM only after the bundle's own key opens it, so it never takes over another caller's VM that reused the name (`RECOVER_UNPROVEN`). `up --sink https-put:<presigned URL>` has the VM upload its own results on a timer, so they survive even if nothing pulls them, and a counted run (`--counted`) refuses to start without a recovery bundle.

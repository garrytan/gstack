- **/investigate's check-after-last-edit item sees fixes written through Bash.** A Bash command that writes a file inside the session directory (a heredoc into python or cat, `sed -i`, `tee`, a `>` or `>>` redirect, `patch`, `git apply`) now counts as an edit, so a run that tests, then fixes the code through the shell and never tests again reads `missing` instead of `met`. Before, only Edit, Write, MultiEdit and NotebookEdit counted, and 5 of 7 probe-I fixes in GEVA-2's L1 run were heredoc writes. The parser (`lib/shell-writes.ts`) is conservative: reads, output to stdout, `2>&1`, and writes under `/tmp`, `~`, another directory or a variable path do not count. (GST-1633)

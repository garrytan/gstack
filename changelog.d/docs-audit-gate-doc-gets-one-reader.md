**/ship can finish when its docs audit corrects a doc the review read, after the last review round.** Before, when Step 14.5's docs audit fixed a line in a gate-path doc (gbrain#10059: "4 times" to "2 times" in docs/guides/secret-store.md) after the round cap, `gstack-ship-receipt write` refused on `review_exclude` and offered only another review round, which the cap forbids, so the receipt had to be waived. Write now refuses with `RECEIPT_DOCS_AUDIT_READ`, writes a packet of the audit's change for one scoped reader, which is not a review round, and binds the reader's clean `--docs-audit-read` record into the receipt as `docs_audit_read` (GST-3532). A reader's finding, a stale record, an edit too large for one reader, or a change git can show only as binary still refuses. The docs audit steps also say a re-audit passes one flag for its one earlier audit: `--carry`, or `--carry-stopped` when that audit stopped first.

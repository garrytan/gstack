- **A PR's review-round count can no longer be overwritten by the body `/ship` posts.** When `/ship` posted a PR body whose Agent notes held their own `gstack-receipt-runs` blocks, gstack removed only the first one, so a second block placed before the receipt became the history `gstack-ship-receipt history` counted (one round where there were three). A post now drops every runs block it brings and keeps exactly one: the live body's history, placed right after the posted receipt, or none when the PR had no earlier runs. See docs/review-policy.md#rounds-per-pull-request.

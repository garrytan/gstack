- **A PR's review-round count can no longer be overwritten by the body `/ship` posts.** When `/ship` posted a PR body whose Agent notes held their own `gstack-receipt-runs` blocks, gstack removed only the first one, so a second block placed before the receipt became the history `gstack-ship-receipt history` counted (one round where there were three). A post now drops every runs block it brings and keeps exactly one. That one is the live body's history, placed right after the posted receipt, or none when the PR had no earlier runs. A post whose notes hold no receipt yet keeps the live started stubs in place of the runs block it brings. See docs/review-policy.md#rounds-per-pull-request.

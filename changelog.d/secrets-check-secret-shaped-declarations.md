**The secrets check now catches keys in JavaScript, TypeScript and Go declarations, and stops flagging names, run folders and base64 noise.** A key written as `const token = "<key>";` (or `let`, `var`, a class field, or Go's `token := "<key>"`) is now flagged when the value looks like a real key: a provider prefix such as `sk-` or `ghp_`, or long random text. A name or word as the value (`const API_KEY = "AUTHENTICATION"`) stays clean. A JSON `"key": "sources/vector-index"` field, an environment-variable name as a value (`API_KEY=OPENAI_API_KEY`) and a `20261123-1711` run folder no longer raise false alarms. A key from your environment is now also found when it appears base64-encoded, and `AIza…` or `sk-…` text buried deep in a long base64 blob is no longer reported. (GST-3500)

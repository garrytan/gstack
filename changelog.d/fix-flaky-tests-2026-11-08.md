- **`./setup` no longer refuses healthy hooks when Bun crashes while checking them.** The hook parse check bundles each TypeScript hook with one Bun process; when that process was killed by a signal (a Bun segfault, seen in Free Tests 42327570347), every hook it hadn't reported was listed as "does not parse" and setup exited 1 with a "this is a gstack bug" message. Now the results Bun printed before the crash still count and the shell checks still run, so a hook that really fails is still refused, and only a hook Bun never reached is registered unchecked. The check reports itself unavailable (exit 3, the same as a missing Bun) only when a hook went unreported and nothing else failed; setup then warns that hooks were registered unchecked, and the auto-updater holds the update as it does for any unavailable check. A Bun that exits normally without a report still fails every hook it left out.
- Two flaky tests are fixed. The gbrain prune test no longer sees another test's `gbrain autopilot` process, and the plan-review floor actor now answers its own cropped "overwrite" permission for the working plan instead of waiting it out.

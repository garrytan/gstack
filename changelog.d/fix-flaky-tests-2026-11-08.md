- **`./setup` no longer refuses healthy hooks when Bun crashes while checking them.** The hook parse check bundles each TypeScript hook with one Bun process; when that process was killed by a signal (a Bun segfault, seen in Free Tests 42327570347), every hook it hadn't reported was listed as "does not parse" and setup exited 1 with a "this is a gstack bug" message. A crash now makes the check unavailable (exit 3, the same as a missing Bun): setup warns that hooks were registered unchecked, and the auto-updater holds the update as it does for any unavailable check. A Bun that exits normally without a report still fails every hook it left out.
- Four flaky tests fixed: the gbrain prune test no longer sees another test's `gbrain autopilot` process, the third-party-actions consent check accepts a defer option that marks the step as waiting on you, and the plan-review floor actor now answers its own cropped "overwrite" permission for the working plan instead of waiting it out.

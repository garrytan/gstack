### Fixed
- **`gstack-ubi pack` works on macOS again.** macOS's built-in tar read pack's options as file names, so `sync`, `run` and `verify` failed after the VM was already created, shipping an archive holding only `.git`. Pack now builds the archive in two steps that work with both macOS and GNU tar, and keeps macOS tar from adding hidden `._*` copies of files that carry extended attributes. (#3680, reported by Jared)
- **`gstack-ubi usage` works on macOS, and the vCPU quota check runs there again.** One line of the usage report was a syntax error for macOS's awk, which also switched off the quota check before every create. `usage` now exits 1 instead of printing a partial count when Ubicloud can't list the VMs or read a size, and the quota check says so in the log and leaves the decision to Ubicloud. (#3679, reported by Jared)
- **`reap` and `up` work on a Ubicloud project with no VMs.** An empty VM list was read as one VM named `-`, so `reap` and every `up` died with `invalid VM name '-'`. (#3678, reported by Jared)

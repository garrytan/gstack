- **/ship no longer stalls planning review on a branch that merged in thousands of data files, and `gstack-review-scope classify` reads a branch diff of any size.** `gstack-review-plan` checked each changed data or docs file for a leading `#!` with its own git call, so a fix range that took in another run's 11,749 trial files spent about 200 s per read of that range on a Capy machine (harness-evals #320 waited 25 to 58 minutes); it now finds those files in a few batched git calls. A plan run by itself now stops at the same 180 s limit `gstack-review-dispatch pass` gives it (`GSTACK_REVIEW_PLAN_TIMEOUT_MS` sets it), printing `REVIEW_PLAN_STOPPED` and no plan, and an unreadable fix range lists its first five problems and a count instead of every file. `classify` failed with an empty reason once the branch diff passed 64 MB; it now reads git's diff from a file, and a failure names git's error or the timeout.

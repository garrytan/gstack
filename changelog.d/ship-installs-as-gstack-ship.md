**`/ship` is now `/gstack-ship`, so Claude Code loads gstack's shipping skill again (#4775).** Claude Code 2.1.331 keeps the name `ship` for its own built-in `/ship` and drops any user skill with that name at startup, so gstack's `/ship` never ran there: typing `/ship` started Claude Code's version, and the model got "A custom /ship isn't loaded". gstack's skill now installs as `/gstack-ship` in both prefix modes and on every host, the `/ship` budget child starts with `/gstack-ship`, and the recovery and resume commands gstack prints say `/gstack-ship`. Upgrading removes gstack's old `ship` entry, keeping any file you added to it, and never touches a `ship` skill of your own; and a `disabled_skills: ship` entry still turns the skill off. Receipts, state folders and the `gstack-ship-*` commands keep their names. On an older gstack, starting Claude Code with `CLAUDE_CODE_DISABLE_SHIP=1` brings gstack's `/ship` back, but it also turns Claude Code's own `/ship` off.

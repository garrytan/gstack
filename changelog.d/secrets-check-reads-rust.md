**The secrets check now reads Rust.** A key written as `let token = "<key>";` (or `let mut`, `const` or `static`, with or without a type) in a `.rs` file was never flagged; it now is, as `env.kv.rust`. Rust type annotations such as `token: Option<&str>,`, `key: &RelationshipKey,` and match arms such as `Token::Char(c) =>` in a `.rs` file no longer read as secrets, so Rust projects can drop their allowlist entries for them. Other languages' files are checked exactly as before; a scan with no file path also reports the new binding form. (GST-3474)

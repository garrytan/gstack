- **/ship's test step says when it ran out of time, and you can set its budget.** `gstack-ship-preflight` used to stop gstack-pregate after a fixed hour and print `PREGATE: unreadable (exit 143)`, which hid the cause. The whole step's budget is now `--step-timeout <s>` (default 3600 s), and a stop at that limit prints `PREGATE: time limit hit` with the way out: push and let CI's full run carry the tests, or give the step a larger budget.
- **The remote test command no longer puts every file on one command line.** On a small machine with a remote `test_backend`, the command pregate prints for gstack's Ubicloud runner used to carry every selected test file in one argument, which Linux refuses past 128 KiB (`E2BIG`). The files now go to the VM in a setup script, so the command stays short however many files are selected. docs/troubleshooting.md has a new `arg-limit` entry for this kind of failure.

- **GitHub release notes now list every change in plain words, with a link to its pull request.** Releases v1.99.1.0 to v1.99.4.0 said only "see CHANGELOG.md", because the release cut took one headline per version and found none in entries written as bullets. Each release page now lists every change the release ships under What's new, Fixes and Changes for maintainers, one line each, with the pull request that made it, then the compare link. A release whose CHANGELOG has no entry for its version, or an entry with nothing in it, now stops with `NOTES_MISSING` instead of publishing an empty page, and notes too long for GitHub keep the changes that fit and say how many more are in the full changelog (docs/releases.md#release-notes).

- **A PR landed onto a moved main no longer runs Free Tests twice.** When `gstack-ship-queue land` merges a PR whose base moved, `land.merged_ci` has already run Free Tests on the merged tree on `gstack-land/<n>`. Main's push run now reuses that run when it passed and tested exactly the tree that landed; when main moved again before the merge, or the newest land run wasn't green, the push run tests the tree itself as before (docs/pregate.md#ci-reuse).

- **Live activity and inspector streams no longer leak when the client goes away.** Closing the sidebar, cancelling a stream or aborting a request before it subscribes now releases the subscription and heartbeat right away, and a subscriber whose teardown throws no longer keeps the stream open.
- **`network --capture` keeps each capture to its own session.** A response that was still loading when you ran `--capture stop` or started a new capture no longer lands in the buffer afterwards, so the count `stop` reports matches what `--export` writes.
- **The docs link checker reads fenced code the way GitHub does.** A shorter fence or a fence followed by text no longer closes a code block, a line of inline code that starts with backticks no longer opens one, repeated headings get GitHub's anchor suffixes, and a file named like `..notes.md` is no longer reported as outside the repository.

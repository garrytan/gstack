**/cso no longer aborts when a tracked secret-like file such as `.env.example` cannot be read.** A Claude Code sandbox rule like `Read(**/.env*)`, or a file with no read permission, made `start` fail with a generic `INVALID_SCHEMA` error. The file is now listed as unread, the source coverage reads partial, and the audit continues. Other files /cso already leaves out of the audit (dependencies, tool state and agent configuration) are handled the same way when unreadable; any other unreadable file still stops the run. Reported by @kado-ta (#4395).

- **When owner rulings don't clear a stopped review, `gstack-review-read` now says which findings are left.** The unverified reason used to read only `missing start capture or incomplete/nonconverged pass`. It now adds each finding that still has no ruling, as `<fingerprint> (<severity>, <action>)`, up to ten, or says the row lists fewer findings than it claims. A finding logged `noted` at CRITICAL is on that list, because a note never closes a CRITICAL; rule it like the others and the review binds (harness-evals#498). A gate finding on that list also names the `gate_id` its gate disposition needs, since a ruling never closes one.

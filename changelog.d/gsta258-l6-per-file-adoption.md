- gstack's own CI carry now runs the test files CI skipped entirely. Free Tests records `skipped_files` (the planned files whose every test skipped on the runner) in its `tested-tree` record, and gstack's `bun run test` lane declares `per_file`, so a /ship carry runs those files locally instead of counting them as run (GST-1190).
- **CI carry no longer refuses a skipped file that skips here too (GST-1314).** `gstack-evidence record-ci` runs the per_file remainder one file at a time. A file whose every test skips here as well, like the six env-gated or tool-gated files Free Tests run 41754278952 skipped (0 pass, 20 skip on a Capy machine), is recorded as not owed instead of ending the carry with `skipped_zero_run` and rerunning the whole free suite. A file that registers no test here still refuses, even next to one that ran. Paths reach the runner anchored with `./`, since Bun reads a bare relative path as a substring filter, and gstack's `per_file` runner passes `--no-env-file`.

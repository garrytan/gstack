- **/sync-gbrain's read check now works when the first page in your code source is over 64 KB.** The check read the whole page just to confirm its source and slug, and a large first page (a lockfile is the usual one) hit its 64 KiB output limit, so every run reported the read as `unknown`. It now asks gbrain for a 4 KB window of the page (`--body window --max-bytes 4096`), which keeps the response small however big the page is. A gbrain from before body windows (0.60.231.0) gets the old whole-page read with the same limit, and output cut off at the limit still counts as `unknown`, never `ready`. Thanks to @nfitzsimmons for the report and the fix (#4396).

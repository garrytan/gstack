**/ship's review no longer stops when Capy's own drive sync database grows past 100 MB.** The per-stage fetch sweep now ignores that database (`state.db` and its SQLite side files under `~/.capy/drive-engine`), so it crossing the download line mid-stage no longer quarantines the stage and blocks every later one. A real download of 100 MB or more anywhere else, `~/.capy/drive-engine` and `~/.capy/work` included, and an existing file a stage writes past the line, still count.

- **`/investigate` is cut (GST-1717).** A preregistered eval found no gain: on 18 real bug-fix tasks that plain Opus 5.5 solves about half the time, 20 trials each, Opus told to use `/investigate` passed 50.0% of trials against 47.2% with no skill (+2.8 points, 95% CI -5.8 to +11.4, below the 10-point lift the run could detect), and a passing fix cost about 43% more ([GEVA-380 R3c](https://github.com/garrytan/gstack-evals/blob/c90ab277/wiki/board/2026-11-07-geva-380-r3c-results.md)). `./setup` no longer installs it on any host, and the next `./setup`, relink or upgrade removes an existing gstack-owned `investigate` / `gstack-investigate` entry, even though its source is gone. A skill you wrote yourself under that name is left alone, and the entry is retired through the `disabled_skills` path so config can't re-enable it. Because the source is gone, gstack can't confirm that a real-file `SKILL.md` left in such an entry is its own unedited copy, so relink moves it to the backup root, and setup does the same for a copied entry on another host that differs from gstack's last render. Your own files in that directory stay. The opt-in /investigate gate goes with it: `./setup` removes its four Claude Code hooks from settings, `gstack-config`, `gstack-skill-gates` and `gstack-skill-route` drop its switch, and `./setup` now rejects `--investigate-gate` and `--no-investigate-gate` as unknown options, so drop them from install scripts. If setup can't remove those hooks, it now prints a warning with the command to rerun. The shared contract stop hook and gate machinery stay, because `/review`, the `/plan-ceo-review` gate and the `/autoplan` gate use them. Bug reports now get fixed directly: one read-only check of the cause, and when it is still unclear, a focused test that fails on the bug before any edit, then the root-cause fix and a rerun. The router, the CLAUDE.md routing block gstack offers, `/ship`'s test-failure triage, `/ios-fix`, `/learn`, `/verify` and the docs say so and no longer name `/investigate`. One line still does: `/review`'s checklist routes timing flakes to `/investigate` until its no-loss replay and repin land (GST-1744), because that checklist is pinned to replay-tested bytes.

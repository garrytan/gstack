- **`/investigate` is cut (GST-1717).** A preregistered eval found no gain: on 18 real bug-fix tasks that plain Opus 5.5 solves about half the time, 20 trials each, Opus told to use `/investigate` passed 50.0% of trials against 47.2% with no skill (+2.8 points, 95% CI -5.8 to +11.4, below the 10-point lift the run could detect), and a passing fix cost about 43% more ([GEVA-380 R3c](https://github.com/garrytan/gstack-evals/blob/c90ab277/wiki/board/2026-11-07-geva-380-r3c-results.md)). `./setup` no longer installs it on any host, and the next `./setup`, relink or upgrade removes an existing gstack-owned `investigate` / `gstack-investigate` entry, even though its source is gone. A skill you wrote yourself under that name is left alone, and the entry is retired through the `disabled_skills` path so config can't re-enable it. The opt-in /investigate gate goes with it: `./setup` removes its four Claude Code hooks from settings, and `gstack-config`, `gstack-skill-gates` and `gstack-skill-route` drop its switch. The shared contract stop hook and gate machinery stay, because `/review`, the `/plan-ceo-review` gate and the `/autoplan` gate use them. Bug reports now get fixed directly: one read-only check of the cause, and when it is still unclear, a focused test that fails on the bug before any edit, then the root-cause fix and a rerun. The router, the CLAUDE.md routing block gstack offers, `/ship`'s test-failure triage, `/ios-fix`, `/learn`, `/verify` and the docs say so and no longer name `/investigate`.

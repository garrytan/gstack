- **/ship no longer stops when the docs checker's reply has a small mistake in it.** Before shipping, /ship asks a helper to check the docs and reply with a short summary line. When that helper typed a field name with a stray space and left the docs summary as a stand-in like "x", /ship treated the whole check as blocked and an unattended run stopped. Now `gstack-docs-candidate result` reads that last line strictly. It forgives spaces around field names, still refuses anything else that's wrong (a missing or extra field, the wrong audit id, an empty or stand-in summary), names each problem, and hands the one retry a note saying exactly which fields to fix. A reply that passes is saved with its summary for the PR. The docs test fixture accepts the new command, and odd audit ids or field names can no longer write outside the record folder or fake a line in the output. (GST-1843)

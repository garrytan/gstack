- **A finished /ship no longer blocks `gstack upgrade` for two hours (GST-1205).** Each gstack workflow now records its own run on the installation's workflow lease when it starts and closes that run when it ends, so once every run on a lease has finished the lease is idle and `gstack-upgrade` goes ahead instead of refusing with `UPGRADE_BUSY` until the lease turned 120 minutes old. A run still counts for 120 minutes from its own start if it never ends, and a lease written by an older gstack counts as before. `gstack-lease list` shows idle leases as `idle`, and `gstack-lease open --run <id>`, which `gstack-ship-preflight` uses to refuse a base merge under an open /ship run, now works instead of exiting with `unknown verb 'open'`.

- **The prompt-routing hook now suggests skills you install yourself, and no longer sends ordinary bug reports to /qa (GST-3123).** Any installed skill that lists `triggers:` in its own SKILL.md can now be named by the hook, next to gstack's /review, /qa and /verify: on 60 real bug reports, a bug-fix skill with a "fix this bug" trigger is named on 40 (it was never named). One line names at most two skills, gstack's own skill wins a tie, and a skill whose name or trigger text holds anything but letters, digits, spaces and simple punctuation is skipped, so it can't write instructions into the line. Separately, /qa no longer takes bug reports on everyday words ("cannot find" plus "fails", or "call site" and "tests" far apart): it took 3 of the 60 and now takes none, while "please test the site" and "find bugs on my site" still route to it. `gstack-skill-route --explain` and the routing log show where each suggested skill came from.

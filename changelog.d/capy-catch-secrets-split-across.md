- **A secret split across two lines of UTF-16 text is now caught, and deleting a large binary no longer blocks a push.** The secret check and the pre-push hook read a file git calls binary three ways (as bytes and as little- and big-endian UTF-16), but they kept all three readings on one line. So in a UTF-16 file, an AWS secret key on the line under its `aws_secret_access_key:` key passed both guards, because the keyword line ended with another reading. Each reading is now scanned as its own text with the file's line numbers, so that pair fails in UTF-16LE and UTF-16BE as it does in plain text. The pre-push hook also leaves deleted files out of the diff it scans (`--irreversible-delete`). A delete cannot add a secret, and the old bytes of a deleted 70 MiB binary used to fill the hook's 64 MiB buffer and block the push with `git diff failed (status=killed/overflow)`. Adding a binary that large still blocks, and a replaced binary's old bytes still count toward the limit.

- **Browse logs no longer keep typed values from page URLs, and short secrets leave error text.** The `origin` field of `.gstack/browse-audit.jsonl` stored the full page URL, so after a GET form was submitted the next line held what the user typed, such as `?user=a&password=hunter2pw`, and `browse-network.log` stored page-issued request URLs with their token query values. Both now keep the scheme, host, path and query parameter names, write every query value as `[REDACTED]`, and drop any username, password or `#fragment` in the URL. The audit error scrub now also removes 2- and 3-character pieces of a redacted value that contain a digit, such as a CVV or an expiry month, matched as whole tokens so nothing inside a longer number or word changes; shorter word pieces like `a` or `is` are still left in the error text so it stays readable. This closes the limits noted for GST-1631. Lines written before this release still hold the old values; delete `.gstack/browse-audit.jsonl` and `.gstack/browse-network.log` to clear them. (GST-1635)

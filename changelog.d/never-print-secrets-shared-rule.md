- **Every skill that loads the shared preamble, on every host, now says never to print a whole environment, git config or process table.** The rule used to load only in the Capy wrapper, and its list missed `git config --list`, which can print a proxy's login header, process or container listings that show arguments or environment (`ps aux`, `ps -ef`, `ps -o args`, `docker top ... args`, `docker inspect`), where run tokens ride, and `set -x` or an `export $(...)` that expands to a bare `export`. A new Ground Rules section in the shared preamble lists these commands and the safe forms, which are to read one value by name (`git config --get <name>`), check a variable is set without printing it, and list processes by name or pid. It also says to wait on CI with one `gstack-pr-wait` call instead of a poll loop or `gh pr checks --watch`, which spends the shared GitHub GraphQL quota. The section is pinned, so no model loadout drops it.

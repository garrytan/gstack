- **Every skill on every host now says never to print a whole environment, git config or process table.** The rule used to load only in the Capy wrapper, and its list missed `git config --list`, which can print a proxy's login header, and process or container listings that show arguments or environment (`ps auxww`, `ps -o args`, `docker top ... args`, `docker inspect`), where run tokens ride. A new Ground Rules section in the shared preamble lists every such command and the safe form: read one value by name (`git config --get <name>`), check a variable is set without printing it, and list processes by name or pid. It also says to wait on CI with one blocking watch instead of a sleep-and-poll loop. The section is pinned, so no model loadout drops it.

- **Gemini CLI is a supported host: `./setup --host gemini` (alias `gemini-cli`) installs gstack's skills into `~/.gemini/skills`.** Auto-detect picks Gemini CLI only when the `gemini` command is installed, so Antigravity's `~/.gemini` folder never selects it. `--local` is refused, because Gemini CLI loads project skills only in trusted folders. Uninstall, the script and the manual steps alike, removes only gstack's own entries from `~/.gemini/skills` and leaves your own skills there.
- **Older installs drop the 520 MB test toolchain on their next `./setup`.** A checkout that has the test and eval packages but isn't marked as a contributor's moves to production-only dependencies once. `bin/dev-setup` now marks a contributor clone with `git config gstack.contributor true`. If the smaller install fails, setup puts the full install back and warns with `SETUP_DEPS_MIGRATE_FAILED`. A second `./setup` started while the first is moving dependencies now stops instead of installing over it.

- **The manual uninstall steps keep your own skills in `~/.gemini/skills`.** docs/uninstall.md now removes only links and gstack-generated folders there, as `gstack-uninstall` already did, so a skill of yours named `gstack-something` survives.
- **Moving an older install to production-only dependencies is safer when it is interrupted.** After an interrupted move, `./setup` now restores the full install it set aside and starts over, so an offline rerun keeps a working `node_modules`. A second `./setup` started while the first is moving dependencies now stops with a message instead of installing over it. The `SETUP_DEPS_MIGRATE_FAILED` warning and its troubleshooting entry now say what triggers the move, which is a checkout that has the test toolchain and isn't marked with `git config gstack.contributor true`.

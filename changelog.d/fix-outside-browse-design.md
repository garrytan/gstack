- **`browse --session <name> <command>` works with the flag before the command.** Before, `--session` in front was read as the command name and failed with `Unknown command: '--session'`. The help and BROWSER.md now also say Windows gets no automatic per-agent session, so each parallel agent there sets `BROWSE_SESSION`. (#4662)
- **The `browse handoff` window no longer opens with a stray blank tab** that `browse tabs` did not list and no command could close. (#4323, #4330)
- **`$D setup` accepts the Gemini keys Google AI Studio issues now, which start with `AQ.`**, and saves a key typed with no `--provider` as a Gemini key. gstack's secret scan and browse's cookie masking now recognize `AQ.` keys too. (#4239)
- **`/verify` trusts a repository's checks in every worktree of it.** Trust was keyed by the checkout folder, so an agent app that starts each session in a fresh worktree asked again every time. The command set still has to match, so a worktree whose checks differ still asks, and only folders git lists as worktrees of the repository share its trust. (#4407)
- **`/context-restore` finds Claude Code transcripts under `CLAUDE_CONFIG_DIR`** (and Codex sessions under `CODEX_HOME`) when a second profile is in use. (#4559)

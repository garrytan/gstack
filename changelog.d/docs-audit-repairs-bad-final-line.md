- **/ship's docs check no longer burns its one retry on a badly shaped reply.** Before shipping, /ship asks a helper to audit the docs and end with one summary line in a fixed format. When that line had the right findings but the wrong shape (a missing field, or a misnamed field holding "x"), /ship counted it as a failed audit and spent its only re-audit, and an unattended run could stop with sound docs. Now `gstack-docs-candidate result` tells a shape-only mistake apart from a real one. For a shape-only mistake it prints `FORMAT_REPAIR:`, and /ship asks a fresh helper with no tools once, using no attempt, to restate just that line: `gstack-docs-candidate repair-prompt` builds the request from the format and the helper's own output. The reply is accepted only if every value the first line already got right is unchanged, so a repair can fill in a field but never change the outcome. A missing or wrong audit id, a missing or unknown status, either one given twice, a malformed list of edited files or blockers, a status that contradicts the file lists, or a last line that isn't JSON at all still counts as a failed attempt, and each audit gets one repair.

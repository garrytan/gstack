- **`gstack-artifact validate` no longer passes a run.json that gstack-autoplan never wrote.** A session that skipped `gstack-autoplan next` and built run.json with a script, copying the reference fixture, got `ARTIFACT_VALID`. The validator now also checks that the run came from gstack-autoplan: run.json must carry `host: gstack-autoplan`, `plan_input` and the other fields it writes on every run, and must agree with its `attempts.jsonl` journal, its bound review outputs and its checkpoint. A run that fails says `ARTIFACT_NOT_AUTOPLAN_RUN` or `ARTIFACT_JOURNAL_MISMATCH`, and `gstack-artifact ack` refuses it too. Public copies (`validate --public`) are unchanged.

**The factory scorecard's `Red-train rate` now counts each merge batch once, so a bisect or a rebuild no longer changes it.** It used to divide red runs by all non-cancelled runs on branches with the batch prefix, so a batch that was bisected and rebuilt weighed more than one that ran once. Now the runs are grouped by head branch: a branch is red if any of its non-cancelled runs failed, and a branch with only cancelled runs is left out (#4767).

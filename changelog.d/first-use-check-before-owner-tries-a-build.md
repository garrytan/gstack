- **A cold first-use check before an app build reaches its owner (GST-3025).** New `gstack-first-use` freezes the first five day-one actions from the plan and the exact build, has an agent from another model family play that build on the same kind of device with a screenshot or video for each action, checks every link within 15 minutes of sending, and prints the "try this build" message only when all of it passes. The owner's score and words are kept beside the checker's predicted score in the owner's private drive. See `docs/first-use-check.md`.

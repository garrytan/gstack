**`gstack-design-lint` names a path it cannot read relative to the folder you ran it from, also when you pass that path through a symlink.** Given a missing file through a symlinked folder (on macOS, a path under `/tmp` or `/var`), the finding printed the full absolute path; it now prints the short one, such as `gone/nowhere.html`. For contributors: `test/design-lint.test.ts` and `test/design-lint-fifth-cycle.test.ts` pass on a Mac again, where four tests compared paths against the unresolved temp folder.

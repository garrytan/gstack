**The prompt-routing hook no longer names your bug-fix skill on bug reports, and gstack's CLAUDE.md bug line drops "a focused failing test first".** In a preregistered test on 183 real Python bugs across Opus 5.5, GPT-6.2 Sol and particle-1 (gstack-evals#426), naming the bug-fix skill got its steps followed in 80% of sessions against 3%, but fixed no more bugs (-1.5 points, 95% interval -3.8 to +0.9). The hook still routes /review, /qa and /verify exactly as before, and an installed skill's other triggers still route; only a trigger that names nothing but a bug and fixing it ("fix this bug", "reproduce the bug in a test") no longer does. `gstack-skill-route --explain --json` no longer prints `bug_report`, and the routing log no longer writes `bug_report=true`. This supersedes the earlier entries that had the hook name the bug-fix skill first and keep feature requests away from it.

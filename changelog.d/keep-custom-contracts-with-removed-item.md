- **A skill you wrote whose contract still lists `check_after_last_edit` keeps the rest of its contract.** This corrects the entry in this release that says such a contract is now invalid and none of its items are checked. The optional Stop hook now skips only that item and keeps checking the skill's other items. Until you delete the item, the hook prints a `SKILL_CONTRACT_SKIPPED` line naming the file and the item. A contract whose only items use the removed kind is still invalid, so the hook checks nothing for that skill.

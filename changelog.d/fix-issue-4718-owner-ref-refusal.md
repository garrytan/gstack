**`gstack-approvals rule` and `round-grant` now say which `--owner-ref` check failed and what a valid ref looks like.** A ref in the wrong shape, a missing `--words` and a missing `--by` each print their own line, and the shape refusal quotes the ref and states the thread code it needs: an uppercase letter, then uppercase letters or digits, a dash and a number from 1. The fix line of every invalid approval record no longer tells you to rerun `gstack-approvals add` with flags the command you ran does not take. (#4718) Contributed by @Barack-zero-to-one

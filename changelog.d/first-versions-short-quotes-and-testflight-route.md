**A first version's public export now keeps out the owner's short quotes and his reasons to leave something out, and a phone first-use check installs a build the cloud phone can actually run.** `gstack-autoplan export --public` used to redact only owner quotes of three or more words, so a one- or two-word quote, or a `leave out:` reason, could reach the public copy through the gate's choice titles. Now every plan quote is redacted wherever it appears directly inside quote marks, and every `leave out:` reason wherever the gate shows it, whatever case the key is typed in; `validate --public` catches either one written back. `gstack-first-use start` for an iOS or Android build now takes `--phone-build <id>`, the Capy mobile build of the same commit, because the cloud phone installs only that kind of build and a TestFlight number left the checker unable to install anything. An iOS or Android run started before this change is refused with a note to start a new one (docs/first-use-check.md).

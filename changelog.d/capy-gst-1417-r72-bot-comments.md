- **Agents comment on GitHub only under a bot identity.** CONTRIBUTING.md (issue triage, the wave process and porting step 5), docs/triage.md, docs/captain.md, docs/recommended-harness.md and /modernize let an agent post the close note, the thank-you, the ask for missing information, tags and review requests, under its bot identity (`capy-ai[bot]` on Capy) and never the maintainer's own account. On Capy, comments and tags go only through `tools.pr.comment` and review requests through `tools.pr.edit`, never `gh pr comment`, `gh issue comment` or `gh api`, because `gh` runs as the maintainer; a comment no bot-identity tool can post is a draft for the maintainer instead. An unattended /modernize run posts nothing. Email, chat, DMs and social posts to people, and reading the maintainer's inbox, stay off limits for agents. (GST-1417)

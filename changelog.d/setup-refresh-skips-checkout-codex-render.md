**`./setup --refresh-registered` run from inside the gstack checkout no longer reinstalls Codex after you removed it.** The checkout's own `.agents/skills/gstack` folder is its Codex skill render, and the upgrade used to mistake it for a Codex install inside a project, so it reinstalled Codex skills into `~/.codex/skills` and added Codex back to the installed hosts. Now only a separate project that keeps its own gstack copy at `.agents/skills/gstack` is picked up and refreshed. Thanks to @schubter for the report (#4835).

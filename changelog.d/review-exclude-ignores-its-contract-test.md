A repository's own test for `review_exclude_paths` no longer pulls excluded files back into review. When a test file that names `review_exclude_paths` quotes an excluded path only as an array entry, such as in the pattern list it pins or the paths it expects to match, that path stays excluded. Code that reads the file, other tests that name it, a quoted path passed to a call, and any joined or prefixed form of the path still keep it in review (docs/ship-policy.md).

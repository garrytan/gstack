- **On Codex, office-hours, plan-design-review and gstack-upgrade work again when you name them.** `./setup --host codex` left a second copy of each of these three skills inside gstack's own folder, so Codex listed them twice and loaded nothing when you asked for one (`$office-hours` started without its instructions). Setup now links those files instead of copying them, so Codex lists each skill once. Re-run `./setup --host codex`, or upgrade gstack, to fix an existing install.
- **gstack knows when Codex is running unattended.** A skill started under `codex exec` (or `codex review`) now reports `SESSION_KIND: headless` instead of `interactive`, the same as an unattended Claude Code run, so it stops with a clear BLOCKED line instead of asking a question nobody will answer. The Codex TUI, and Codex inside Conductor, still count as interactive.
- **Codex reviewers start with a clean context.** The design reviewers, /autoplan's review phases and /context-restore's summary helper now start their Codex subagents with `fork_turns: "none"`, so they no longer inherit the parent's whole conversation (GST-3091).
- **Docs no longer say Codex has no hook support.** Codex CLI 0.170 runs hooks; gstack's routing, contract and destructive-command hooks just aren't ported to it yet.

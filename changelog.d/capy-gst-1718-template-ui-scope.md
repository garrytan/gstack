- **/ship now notices a screen written as a Lit or htm template inside a .ts or .js file.** `gstack-diff-scope` counted only CSS, .tsx, views and similar files as frontend, so a pull request that rendered its UI from tagged `html`` templates in plain TypeScript read `SCOPE_FRONTEND=false`, and /ship skipped its design-lite check and the design reviewer without saying so. qm#3186 shipped three visible spacing problems that way. A changed non-test .ts/.js file that holds a tagged `html`, `css` or `svg` template now counts as frontend when one of its changed lines carries markup. Logic-only edits and TypeScript generics don't count. SCOPE_BACKEND is unchanged, so those files still get the backend reviewers. Replayed on the last 100 merged gstack PRs and the last 100 merged qm PRs, no scope flag was lost, and only SCOPE_FRONTEND gained (qm only). On a rendered-UI diff the ship receipt now records `design: { mode: static, reason: no preview declared }`, and the PR body's Design Review line says the same: no rendered /design-review runs inside /ship yet.

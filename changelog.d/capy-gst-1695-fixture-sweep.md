- **A test run's fixture repositories no longer quarantine a /ship review pass.** /ship's fetch sweep counted any new git repository with a network remote under the temp dir as a reader's fetch, so a lane's background `bun test`, or a reader's own run that hit Bun's 5 s timeout before its cleanup, left fixtures such as `/tmp/ship-bin-*` (origin `https://github.com/fx/fx.git`) that quarantined the stage and then stopped its rerun with `FETCH_RERUN_BLOCKED`; three /ship passes were lost that way on 11-06 and 11-07. Every `bun test` process now puts its temp paths under one root carrying a `.gstack-test-fixture` marker (`TMPDIR` points there, so children spawned with the test's environment follow; a `Bun.spawn` child given no `env` keeps the original temp dir) and removes it after the last file, even after a timeout. The sweep skips a marked root below a sweep root and a repository whose remotes resolve to a local path through `url.<base>.insteadOf`, and prints a `FETCH_IGNORED:` line for each; an unmarked clone with a real network remote still quarantines the stage and blocks its rerun. (GST-1695)

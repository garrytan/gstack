**Skill routing no longer fires on subagent hand-backs or on a passing mention of "code review".** A subagent's report that Claude Code delivers under "Another Claude session sent a message:" in an `<agent-message>` block is now skipped like other agent messages, so it no longer starts an unrequested /review or /verify run and the Stop block that followed (#4801). A trigger that is only a noun phrase ("code review", "pre-landing review"), or a trigger's words in another order ("pr review"), now routes only when the sentence asks for the work ("can you do a code review", "run a code review on my branch", or just "code review"), so a sentence that only mentions it routes nowhere (#4802). Each `routed` line in `hooks/skill-route.log` now records the prompt's length, the trigger that matched and the prompt's kind (typed or which agent wrapper), and `no-route` lines record the kind too, still with no prompt text (#4805).

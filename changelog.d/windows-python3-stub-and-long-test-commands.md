**On Windows, an update no longer deletes your brain-aware skills when `python3` is the Microsoft Store alias.** That alias stays on PATH next to a real Python and exits 49 without running anything, so `gstack-config gbrain-refresh`, which runs after every team-mode update, read a healthy gbrain as "not detected" and removed the brain-aware render. A Python that does not run now counts as absent (the next Python, then a plain-text read, is used instead), and when gbrain's state cannot be read at all the existing render is left in place. Thanks to @Barack-zero-to-one for the diagnosis and tests (#4752). A pre-ship test command longer than the 8,186 characters Git Bash keeps is now split to fit, or refused with a clear "argument list too long" message, instead of starting cut off and failing with an empty log (#4773).

**A quarantined test that the runner skipped now fails the run instead of passing it.** `gstack-flaky` treats a skip on the attempt that decided the run as a quarantined failure, because a quarantined test still has to run; a test skipped first and passing on the retry still passes (#4550, fix found in #4551). Also: "Not now" on the upgrade prompt now sticks for git installs, because the snooze snippet takes the whole `UPGRADE_AVAILABLE` line and keys on the same field the update check reads (#4561); `gstack-models resolve` and `list` read a custom Codex provider's `config.toml` model the way `gstack-codex-probe role-ready` does, instead of always saying no model is set (#4491); and the /browse skill now says that `$B eval` reads files only from the temp directory or the daemon's working directory, and that the daemon belongs to the git root you run `$B` from (#4557, #4558).
